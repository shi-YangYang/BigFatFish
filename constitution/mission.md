# 项目使命

BigFatFish 是开源、跨平台、插件化的 AI 养成软件，让用户长期运行一条拥有持续人格、记忆、兴趣与经历的 AI 鱼。

产品基线是 [产品设计目标 v1.0](../BigFatFish_产品设计目标.md)。基线中的功能和系统支持描述是目标，不代表当前已经实现或验证。

## 用户与价值

- 普通用户通过 Windows/macOS 桌面应用完成引导、聊天和养成。
- 进阶用户通过 QQ、B站、抖音连接同一条鱼，或在 Linux VPS 长期运行。
- 开发者通过插件扩展平台、工具、模型和辅助服务。
- 用户拥有自己的配置、人格、记忆和经历，并能备份、导出、恢复和迁移。

## 核心原则

1. 一个独立 Runtime，多种入口；Desktop、CLI、未来 Web Console 共用核心业务。
2. Runtime 统一管理人格、记忆、模型、调度、权限和平台插件；入口不得直接操作数据库或平台插件。
3. AgentEngine 抽象隔离 DSH Harness；模型上下文和 Agent Session 不等于长期记忆。
4. 养成体验与专业控制台并存；心情和成长是产品状态模拟，不声称真实意识或情感。
5. 授权和审批约束主动行为；保护密钥、账号、浏览器会话和审计数据。
6. 复用成熟项目，通过 Adapter 接入；集成前核对上游接口、依赖及许可证，不粗暴复制仓库。

## 非目标

第一阶段不自研模型或重写 DSH、B站、抖音成熟能力，不扩展大量平台，不提供复杂多用户、多鱼托管 SaaS，不默认无人审批执行社交写操作，不让核心能力依赖公网管理服务。
