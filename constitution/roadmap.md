# 项目路线

阶段与验收目标来自 [产品设计目标](../docs/product-design.md#16-开发路线与验收标准)。当前只有仓库初始化，以下产品能力均未验收。

| 阶段 | 范围 | 验收目标 | 当前状态 |
| --- | --- | --- | --- |
| P0 工程骨架 | Monorepo、规范、文档、CI、Runtime 生命周期、CLI、SQLite 与数据目录、桌面壳 | Linux CLI 启动空 Runtime；Windows/macOS 桌面壳构建通过 | 仓库初始化已完成；运行工程待实现 |
| P1 最小可用 AI 鱼 | DSH Adapter、模型配置、聊天、人格、会话存储 | 配置模型后稳定聊天，重启保留会话 | 未开始 |
| P2 记忆和养成 | 记忆、日记、兴趣、经历、主页、时间线 | 经确认的记忆可跨会话检索 | 未开始 |
| P3 QQ | NapCat/OneBot 适配、主人识别、消息、权限、审计 | 测试小号稳定收发，Runtime 重启恢复连接 | 未开始 |
| P4 B站 | 现有项目适配、观看记录、记忆、插件健康检查 | 活动记录进入统一日记 | 未开始 |
| P5 抖音 | 上游审查、浏览器管理、观看、互动、审批 | 任务不争抢浏览器，未批准写操作不执行 | 未开始 |
| P6 多形态发布 | Tauri、systemd、Docker、安装、更新、备份恢复 | Windows/macOS 可安装，Linux 可纯 CLI 长期运行 | 未开始 |
| P7 Web 与插件生态 | 远程控制台、SDK 文档与示例、插件目录 | 第三方按 SDK 开发独立插件 | 未开始 |

## 最近一步

[Spec 001](../specs/spec-001-repository-initialization/spec.md) 的目录与文档初始化已完成并独立验收 PASS。下一步单独规划 P0 运行工程：确认工具链与依赖版本、API/IPC 方式、数据目录和生命周期契约，再实施 Runtime/CLI 与最小桌面壳。

DSH、B站及两个抖音项目的确切来源、版本、接口与许可证需在相关集成编码前核对；当前不作兼容性结论。每个阶段按相应 Spec 验收，目录存在不算功能实现。
