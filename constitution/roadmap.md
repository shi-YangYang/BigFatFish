# 开发路线

[产品设计目标](../docs/design/product-goals.md) 将初始工作分为 P0–P7。表中列出各阶段计划交付的能力和预期验收方式，已取得的证据另记在阶段记录和对应规格中。

| 阶段 | 交付目标 | 计划验收方式 |
| --- | --- | --- |
| P0 工程基础 | 单仓库、Runtime、CLI、SQLite、数据目录、基础 API、桌面壳、CI | 生命周期/认证/持久化测试，Linux CLI 实跑，macOS/Windows 桌面构建 |
| P1 AI 鱼核心 | DSH Adapter、模型、聊天、Session、人格、消息流 | 真实引擎协议集成、流式消息、重启持久化；模型凭据实测单列 |
| P2 记忆养成 | 长期记忆、来源、日记、兴趣、经历、心情、主页 | 跨会话检索、修改删除导出、状态和 UI 联动 |
| P3 QQ | NapCat/OneBot 私聊群聊、主人权限、统一会话 | 协议测试、授权账号收发和重连实测 |
| P4 B站 | 复用既有项目、插件接入、观看与记忆、健康状态 | 上游源码/许可证审查，适配测试，账号实测 |
| P5 抖音 | 两项目复用、共享浏览器、观看理解、授权互动、调度 | 队列互斥、权限拦截、上游适配、账号实测 |
| P6 跨平台发布 | Windows/macOS 安装包、Linux CLI/Headless、Docker/systemd、更新备份恢复 | 各系统构建与安装、后台生命周期、真实恢复测试 |
| P7 Web 与插件生态 | 经认证远程管理、插件独立安装启停更新、SDK/示例/开发文档 | 控制台真实 API 联动、插件生命周期与权限、开发者示例运行 |

P7 之后的规格继续完善了桌面与 Web、QQ 授权与联系人、人格卡和按会话隔离的笔记，并取消平台逐条审批。Spec044 将聊天页历史限定为本地对话，Spec045 整理了项目目录和文档。历史实测及缺项见 [P0–P7 验证范围](../docs/progress/development.md#p0p7-验证范围)，各项需求和验收见 [规格索引](../specs/README.md)。
