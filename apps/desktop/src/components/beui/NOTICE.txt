Local adaptations:
- Relative imports and local dependency closure. Button retains its data-beui marker,
  explicit 40px/32px/icon sizes, 8px radius, 0.98 press scale, and no hover scaling.
- Input onChange additionally passes the actual React ChangeEvent; native input
  types, refs, required/min/max and browser validation remain available.
- Select accepts a stable external id and native Motion button trigger attributes,
  uses combobox semantics and 8px corners, consumes Escape before its parent Drawer,
  and portals options outside clipping containers into the current dialog scope
  (or body). Anchor measurement follows scrolling/resizing; hidden lists stay inert.
- Checkbox label accepts ReactNode and always names the control from the label
  text rather than including its decorative SVG title; the product Field adapter avoids nested labels.
- Collapsible uses measured-height transitions without layout projection, preserving
  keyboard, focus return and inert semantics. Product disclosure triggers use a
  fixed press scale of 1, no ripple, and a subtle sea-blue hover surface.
- Chinese tab/panel ids use encodeURIComponent so different labels cannot collide.
  TabsList scrolling accessible labels are localized for the Chinese interface.
- Drawer close label is localized. Focus-trap candidates exclude hidden/inert
  descendants. Popover dismissal consumes Escape and portals into its dialog scope.
- Popover geometry shifts and flips the panel within the visual viewport, follows
  scroll/resize, and bounds long content with scrolling while retaining its morph.
- PromptInput adds a product-owned footer and independent submitDisabled control;
  Enter defaults to newline, IME input is left intact, submitted text is not trimmed,
  and controlled draft clearing remains the Chat owner's responsibility. Busy or
  disconnected submission does not disable editing; locked/no-model input does.
- Message entry point omits unused MessageScroller re-exports. App composition uses
  Message/MessageAvatar/MessageContent/MessageBubble, with soft user and ghost
  assistant bubbles; it owns all conversation and request state.
- BounceSidebar permits no active item while a separate settings item is selected.
- Upstream empty TypeScript interfaces use equivalent type aliases for local lint;
  TooltipSurface exposes its side as a data attribute instead of an unused binding.
- Controls, UI and Surfaces adapters supply the application's sizing, labels and
  composition. Tailwind utilities and semantic tokens share the existing 14px root
  and DS blue palette, without importing full Preflight.

Native boundaries: generic JSON/persona/long-text textareas (beUI has no matching
standalone Textarea); hidden native file inputs behind beUI Buttons; native audio;
brand images and semantic content/list/layout containers. Select's hidden validation
input retains the browser form validity contract. No Runtime/API/permission state
is delegated to the component library.

Dependencies added for this source closure: lucide-react 1.67.0 and
@floating-ui/dom 1.8.0. Existing Motion/Tailwind/clsx/tailwind-merge versions retained.
