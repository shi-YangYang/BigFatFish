# Decision — QQ 有界表情工具

## Context
用户要求加上社区大肥鱼人设所描述的发图能力。现有 QQ 自动回复只有文字，手动媒体已有 PNG/JPEG 发送。

## Decision
用户补充网络图片与内置并用：内置大肥鱼娘原创衍生表情、用户上传，以及固定梗鲸公开图库。由可信内部 QQ 回合工具提供列出/搜索/看图/选择，图片真实交给模型理解；选择仅在本轮暂存，最终统一受控发送。每条自动回复最多一张，目标固定，不放开普通插件权限。网络图片来源链接保留，按需读取，不批量抓取打包。

## Reason
仅写人设不能提供图片能力。当前回复链路已有取消、账号、收件人和记忆范围守卫，复用它可避免工具立即发图绕过最终检查。自带本地库可直接使用且不依赖 QQ 收藏内容或网络 URL 有效期。

## Alternatives
NapCat fetch_custom_face 返回 URL 列表，后续可在明确需求下接入；此轮不引入任意 URL 下载。梗鲸官方仓库明确允许 CDN 热链并提供结构化目录，适合无新增密钥的定向网络表情。AI 生图另需模型/服务，本轮不增加。

## Consequences
用户可控制表情内容/启停；图片和工具会增加正常聊天时的模型输入。开发验证仅使用隔离本地模型与 OneBot。实际 QQ 收发与各云模型工具支持由用户后续实测；代码验收不得替代此证据。

## Implementation Constraints
采用增量 schema 7 的 qq_stickers / qq_sticker_options，归档 plugins 范围包含表情与开关，并兼容 schema 6。单张2MB、48张/24MB上限；上传与恢复统一完整解码。内部 restoreArchive 改为 Promise，在原实例锁和 staging 事务中等待校验，公开 HTTP/CLI 的恢复完成语义保持。

图片工具使用 DSH 附件服务确认结果后授予本轮选择资格；私有随机 receipt 只在本次引擎运行与桥接之间流转，不进入模型或插件manifest。图片读取成功本身不代表模型看图成功。首次独立验收发现失败资格未撤销，R1 已按此职责修复，具体验证见 Spec028 rework.md。
