# Decision — 平台操作直接执行

## Context
用户指出「待审批」未被删除，并于 2026-11-06 明确选择「全部取消，操作直接执行」。此前 Decision015 只取消 QQ 审批。
## Decision
取消剩余抖音逐条审批及 Desktop/Web 全局审批入口，CLI/API 同步直接执行。保留插件/账号授权、联系人范围、暂停/取消、精确请求匹配、单次提交与未知结果保护。未验证协议不因取消审批获得支持。旧审批入口明确退役，历史待办不执行、不破坏性删除。
## Reason
已授权范围内一次操作即可完成，避免重复提交与审批造成的多余步骤。
## Alternatives
不采用隐藏入口但保留后端等待审批，也不采用内部自动批准旧审批。直接使用现有活动任务和结果记录。
## Consequences
取代 Decision010/015/019 及旧文档中仍要求抖音逐条审批的规则；不改变插件授权或平台允许范围。无 schema migration；新写 API 需幂等请求 ID。详见 Spec041。
