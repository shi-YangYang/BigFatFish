# 分层记忆与主人关系

QQ 主人的身份依据是本机配置的唯一主人 QQ 与已核实的入站作者。扫码得到的是鱼的账号。桌面把本机对话作为主人入口，B站、抖音的平台账号不用于认主。用户选择在 QQ 群内认得主人，但保持群聊的公开受众和原工具权限。身份不由昵称、QQ 群头衔、模型生成或一条记忆授予。

参考[腾讯云 Agent Memory](https://cloud.tencent.com/document/product/1813/132100)的逐层溯源。保留原始消息与实际活动，把有证据的陈述作为单条记忆，按话题和对话范围组合场景，从确认的偏好、关系和绑定信息形成核心画像。Spec046 先实现关键词检索。

[Spec047](../../specs/spec-047-semantic-recall/spec.md) 在这套设计上加入可选的本地中文语义检索。用户首次启用时下载 BGE small zh v1.5 INT8，之后在本机 CPU 编码。向量是可重建的索引，原文、状态和可见范围以主库为准。自然对话候选的提取单独使用已配置的聊天模型。

同一条鱼共用本地 SQLite，先判定可见范围，再检索组装。视频观看是鱼的经历，兴趣推测是候选；看过不代表主人喜欢。本机/主人私聊的显式委托可以在原记忆表留有出处；一般偏好沿用候选确认。保持用户可纠正、删除，不对实机旧聊天自动回填。
