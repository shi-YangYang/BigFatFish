# 聊天页只显示本地对话

## 背景
QQ 私聊与群聊在后台各自保存上下文。桌面聊天页读取所有来源的对话，历史中会出现这些连接消息。
## 目标
Desktop 与共用该界面的 Web 聊天只展示用户在本地聊天入口发起的对话，包括已有历史与新消息。
## 非目标
此次不删除消息，不调整平台自动回复、上下文、连接页操作记录和记忆整理。
## 当前行为
聊天页优先选本地对话，但历史抽屉仍可打开外部只读会话。
## 目标行为
聊天页只列出并可进入本地对话。仅有外部对话时，打开聊天即可开始新对话，不订阅外部的消息流。
## 功能需求
按已有会话主体判断来源，主人通过 QQ 发的消息同样归 QQ。普通本地对话即使标题带 QQ 也可见。
## 边界条件
历史数据直接按原来源生效。外部会话数量不应挤占本地历史条数。核对 B站与抖音的实际数据路径。
## 技术约束
沿用已有存储和独立会话，无需迁移。使用 Desktop 原生桥和 Web 网关均支持的读取方式。
## 兼容性要求
保留 CLI、记忆与渠道使用的原会话接口。按项目现有客户端和 Runtime 的兼容约定处理来源标记。
## 验收标准
- [x] 聊天首页、历史和订阅仅展示本地对话，混合来源及仅外部两种情况正确。
- [x] 已有记录无需清理，平台上下文和本地对话历史可继续使用。
## 待确认问题
无。
