# Spec：浅海蓝与轻量选中底色

## 背景
用户否决Spec017高饱和纯蓝的观感。dev基线9557f0a，开始干净。当前Done，新独立验收PASS；用户已明确选择“浅海蓝，更清透轻盈”。
## 目标
蓝色与大肥鱼娘形象协调，页面安静、耐看；主操作有强调，页签等选中态保持轻量。
## 非目标
不改布局、间距、尺寸、交互、品牌素材、依赖或数据，不重打发行包。
## 当前行为
高饱和#0866E6同时用于主按钮和页签实心底，选中态与主操作同等抢眼。beUI pill页签还有独立白字覆盖层，不能只换浅底而遗漏文字颜色。
## 目标行为
主操作采用海蓝#22789F、悬停#1D668A，页签/导航选中采用浅水蓝底#ECF8FE和海蓝字；焦点、边框、气泡使用同系轻淡颜色。保留成功/警告/错误及平台识别色。
## 功能需求
1. 从现有共享token调整整套颜色，不追加重复覆盖。
2. 在产品页签样式层明确选中背景及data-tabs-label文字颜色，保留beUI动画、键盘和遮罩逻辑。
3. 主按钮白字可读；选中标签不能因浅底留下白字。
## 边界条件
默认/选中/悬停/焦点/禁用；页签文字覆盖层与主按钮foreground独立。
## 技术约束
纯颜色S0，预计仅style.css及必要主题/产品样式引用；不改底层状态逻辑。
## 兼容性要求
共享Desktop/Web颜色保持一致，Spec016间距保留；旧DMG不包含本轮源码。
## 验收标准
- [x] 全套颜色呈浅海蓝观感，主操作/选中态层级清楚。
- [x] 页签浅底深字，主按钮白字可读；只改展示颜色。
- [x] 当前预览代表状态目视通过，新独立验收PASS。
- [x] 按持续授权本地commit，未push，未打包边界准确。
## 待确认问题
无。用户已明确选择浅海蓝，取代此前蓝灰候选。
