# Spec：模型连接诊断与推理强度

## 背景
用户要求为连接增加测试连接、获取模型列表、设置推理强度，并允许联网查阅相关规范。现有提供商为OpenAI兼容与DeepSeek；功能放在现有「设置 → 模型」配置页。当前Done，官方规范与固定DSH适配细节已核实，返工后新独立验收PASS。

## 目标
用户可对当前填写的连接获取服务端模型列表、选择或手填模型、执行一次小请求诊断，并保存实际影响生成的推理强度。Desktop/Web共享相同行为与beUI组件。

## 非目标
不新增其他提供商或Responses API架构，不重写引擎，不添加temperature等未经请求的参数，不改平台连接业务，不升级依赖、不分包。没有真实账号时不声称云端验证成功。

## 当前行为
Models仅可保存提供商、地址、模型名、密钥和已有高级参数。Configuration加密密钥，查询只返回hasKey；DSHAdapter使用固定0.2.2-alpha.2的OpenAI Chat Completions或DeepSeek Messages。未配置推理控制，自定义bff模型缺少推理能力声明。原生代理默认请求超时5秒，不能直接承载模型诊断。

## 目标行为
- 「获取模型列表」使用当前草稿的提供商、地址、密钥，不需要先保存或填写模型名；结果使用beUI Select供选择，同时保留手工名称输入。空列表、失败和不支持发现有明确局部反馈，不填入虚构模型。
- 「测试连接」发送一次最小文本生成请求，按所选协议、模型和推理设置验证响应，展示成功与耗时；不写聊天记录、人格、记忆或默认路由。仅在点击时执行，明确短提示会消耗少量token。用户已明确选择实际调用所选模型并显示耗时。
- 两操作可用于新配置与已有配置。密钥留空时仅在提供商及规范化地址与所选已保存配置一致时复用存储密钥；地址/提供商变更不能把旧密钥自动发送到新端点。新配置允许无密钥本地服务；明确空apiKey的API语义为不使用密钥。
- 推理强度提供默认及协议支持的显式值。OpenAI兼容为none/minimal/low/medium/high/xhigh/max；DeepSeek为none/low/high/max。中文展示，默认省略新字段以兼容旧配置；none表示显式关闭，不能用省略参数冒充关闭。
- OpenAI列表不宣称包含推理能力；各模型是否接受具体参数以服务为准。服务返回的有效能力元数据可供显示/约束，但不静默改写用户已有高级参数。
- 持久化与DSH真实生成链路均使用推理设置，重启及恢复会话后生效；只修改推理强度可用于已有会话，仍保护被使用配置的地址、模型及其他原有受限字段，运行中请求保留原快照，后续请求采用新值。

## 功能需求
1. Runtime新增认证保护的模型发现/测试接口；共享现有URL规则、密钥解析及推理映射，禁止前端直连提供商。
2. 有界超时、响应大小/条目数量及输入校验；禁重定向，沿用HTTPS远端/HTTP回环地址规则；无查询或响应泄漏密钥、上游错误正文或内部栈。
3. 区分鉴权失败、权限/模型不可用、速率限制、地址/接口不匹配、超时、网络错误和格式不合法；成功须有合法预期响应，不以任意HTTP200假报成功。列表成功不等于模型可生成。
4. 诊断端点使用固定短提示，无历史/工具；输出上限与时间有界，不自动重试收费请求。返回必要结果与耗时，不透出上游原始响应。
5. 异步结果绑定发起时的草稿；切换配置或修改连接/模型/推理参数后不显示旧测试成功，不把旧列表覆盖新连接。按钮有明确等待/禁用状态，反馈局部显示。
6. 保留保存、删除、默认用途、密钥不回显、原草稿与统一40px控件。只为新增诊断路由延长原生代理超时，不扩大所有请求。

## 边界条件
未保存/已保存/无密钥本地服务、地址末尾斜杠、DeepSeek默认anthropic路径、错误/空模型列表、重复或过长模型ID、HTTP401/403/404/429/5xx、重定向、超时、超大/错误JSON响应、服务忽略或拒绝推理值、请求中编辑及切换配置、旧配置缺字段、已有会话恢复、380px窄屏。

## 技术约束
固定现有DSH与依赖，采用正式SDK/插件配置接口，不修改node_modules。模型能力声明与reasoningEffort必须映射到真实wire字段。新代码为现有Runtime ai与前端普通模块，遵守层次；可适度拆出连接服务和模型表单诊断逻辑，不堆入无关基础设施。

## 兼容性要求
ModelConfig可选推理字段存入现有config JSON，无schema migration。默认缺省行为保持，旧备份/已用模型不因新增默认字段误报冲突；备份恢复仍能验证此字段。新诊断不保存任何配置/密钥；普通保存仍由现有按钮触发。

- [x] 默认/关闭/各协议推理等级保存、重载与真实DSH请求payload对应，恢复会话采用新设置；受保护模型身份不被放宽。
- [x] 新接口有认证、URL/凭据/重定向/超时/响应界限保护，不落库或泄漏密钥；分类结果准确。

无。用户已确认实际请求；采用固定适配器profile默认值实现推理配置，避免SDK显式effort在resume后粘住；细节见Plan。
