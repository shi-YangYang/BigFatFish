# 能追溯到原话的人物资料

用户希望大肥鱼分清聊天原话、值得以后想起的事，以及对一个人的简要了解。用现有聊天模型和实际运行的 Runtime 验证，在验证和修复后本地提交。

| 层 | 例子 | 用途 |
| --- | --- | --- |
| 原始消息 | 「我是男生，今年 23 岁。我约好周六去体检。」 | 保留发言人、时间、会话和原话，供核实。 |
| 重要记忆 | 已约好周六体检，或明确说过的个人事实 | 后台从已完成的对话中整理，有出处，可纠正和删除。 |
| 人物资料 | 性别「男」，自述年龄「23 岁」及其来源日期 | 按可信身份和当前场合汇总已确认的信息，新聊天也能使用。 |

- 只用本人明确陈述或有依据的人工纠正生成资料。未知资料可缺省。年龄保留说这句话的日期，不按年份推断生日。姓名、称呼和稳定偏好继续沿用已确认的证据。群里提到其他人的资料不能写到发言人名下。
- 同一人的更正影响后续使用，旧消息仍可作为历史证据。忽略、删除、人工编辑和取消共享应同步影响资料。桌面主人、QQ 好友和各群遵守已有的身份与可见范围。
- 「我的鱼 → 记忆」可以区分人物资料和重要记忆，追溯原话。平台对话保持在原入口。
- 真实验证通过正常对话接口向实际配置的聊天服务发送合成陈述，验证后台整理、跨新会话召回、更正和重启后的持久结果。测试用独立数据目录，无需向真实联系人发送消息或在当前人物资料中写测试值。未成功取得真实返回不能标为通过。
