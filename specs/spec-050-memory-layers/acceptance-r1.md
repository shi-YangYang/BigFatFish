# 人物资料归属独立复验

**通过。** 首轮复现的两处亲属资料错记，以及真实测试发现的对话指令误入重要事项，均已在实际链路修复。

- **本人和亲属。** 分析器写入年龄、性别前核对整条消息，以及同一会话、同一发言人的上一轮问答。没有第三人话题时的「男，23岁」仍可作为本人自述。云端五轮实测中，妹妹的「女，19岁」和回答弟弟年龄的「17岁」均未改动主人的两项资料。新会话正确答出主人为男、23 岁。[真实对话记录](live.md)
- **重要事项和原话。** 修复后单独向真实模型重发「下面聊聊我弟弟，你先问我他今年多大。」。大肥鱼正常追问，原始消息已保存，重要事项和人物资料均为零条。分析器逐句筛选，独立明确的自述仍可保留。[真实对话记录](live.md)
- **已有证据和可见范围。** 生成资料时再次核对来源。仅记忆备份缺少原消息时，已验证的证据链接可保留原有资料；旧档中无核验标记、又无法指明本人的年龄简写不会被提升。已核对更正、删除和群聊回归断言，主人私下更正年龄后，来源群仍看到群内自述，另一群查不到。

本轮复验审查了生产代码、定向断言和云端实测记录。复用已通过的 15 项分析用例与 8 项投影、归属及归档用例，未追加云端请求。其余范围沿用[首轮验收](acceptance.md)。
