# 实施与验收

沿用 SQLite、现有消息和有来源的事实，明确人物资料的字段、身份、适用场合与更新时间。让产品页面和聊天上下文使用同一来源，不另建需要单独安装的服务。

涉及人物归属、持久化与跨会话召回，按 S3 验证。先用云端模型复现现状，再用合成数据检查三层结果和跨新会话回复。补充受控的隔离及人工改动用例，独立验收后将累计的记忆系统改动一并本地提交。真实模型标识、实际现象和未测边界见[真实测试](live.md)。

真实基线发现两个有关联的漏项：年龄和性别被合并进一条“男生”事实，新会话提问时没有当成人物资料；“小猫名字”也没匹配到已经保存的猫名。纳入本次修复，并用同一条复合问句重测。

## 实施结果

schema 11 用关联重要事实及证据的字段保存人物资料。来源日期按本机日历日显示。可以从资料回到原话，编辑或删除相应事实；仅记忆备份恢复时沿用已核实的证据。云端实测修复了多事实拆分、更正、宠物名字召回，以及第三人资料和本轮聊天指令误入记忆的问题。

生产 WebUI 经 HTTPS 在 Chromium 中验证，另使用真实云端对话产生的数据在界面打开年龄来源。原始消息、数据库、资料接口和重启后的云端回答分别核对。测试与用户的日常数据隔离，未在 QQ 实发。首轮与返工见[独立验收](acceptance.md)和[真实测试记录](live.md)。
