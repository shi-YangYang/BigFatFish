# 自然对话记忆与本地语义检索

主人在桌面或 QQ 私聊用自然语言讲述经历、计划、偏好时，使用已配置的聊天模型自动提取少量有本人原文依据的候选，在已有记忆页确认或纠正。已有明确称呼指示继续生效。普通闲聊、他人猜测、识别内容不能直接成为主人事实。仅处理新完成的合格回合，保护更正、遗忘、取消、换绑，不批量上传旧聊天。

桌面记忆页可首次开启中文语义检索，由 Runtime 下载固定版本和校验和的 BGE small zh v1.5 INT8，在本地 CPU 推理。无需额外 Key 或服务。首次下载、失败、重试可见；关键词查询在未就绪时可用。已确认事实、可见的当前场景笔记、鱼的实际观看事件使用可重建的本地向量索引。先限定受众、真实来源与状态，再做语义和词法检索；优先保留姓名/称呼和原有时间与平台过滤，停用/撤回不可读。编辑、删除后禁止返回过期内容。

验收用私聊自然陈述、无共同关键词的改写、群聊/好友反例、更正删除及旧数据库；实际运行量化模型验证召回与耗时，明确可验证的平台。不使用真实账号发送或云模型测试。
