## Spec Coverage

- **自然对话生成候选。** 桌面与绑定主人的 QQ 私聊在回复完成后，使用当前聊天模型异步挑选可追溯的本人原句。写入时重新检查发言人、消息和绑定。模型只能选择给定句子，候选需经确认才进入事实检索。已处理原消息的水位独立于候选，拒绝、纠正和删除不会触发原句重学。既有明确称呼指示仍按原流程处理。
- **本地语义回忆。** 记忆页可以启用、取消下载、失败重试和停用，Runtime 重启会按已保存的启用状态恢复。权重及分词文件固定版本、逐个核验长度和 SHA-256。真实推理使用随发行资源提供的 Node worker 和 CPU WASM。已有 SQLite 原始资料可建立独立索引；编辑、删除和降低可见性在读取时按原表和当前范围生效。
- **语料与入口。** 混合检索覆盖已确认事实、当前场景笔记以及有真实观看事件的 B站与抖音经历。QQ 群聊和好友按各自范围检索；当前笔记可见范围、主人私有资料、撤销共享和换绑的判断沿用 Spec 046 返工验收通过的边界。跨入口夹具检查实际交给模型的资料，平台与时间约束仍生效。
