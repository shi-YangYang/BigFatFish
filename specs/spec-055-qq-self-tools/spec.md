# QQ 互动工具与自主账号生活

状态：Done。风险 S3（平台写操作、身份边界、持久化去重与后台执行）。基线 dev / 655d75e；[返工独立验收 PASS](acceptance-r1.md)，无待返工。实现未提交，未应用到真实用户实例。

## 背景与目标
用户要求丰富 QQ 工具，能够修改自身头像、简介并发说说；已明确选择「它可以自行更换头像、简介，并自主发说说」以及补充「撤回自己的消息、读近期消息、群名片等」聊天互动。此前取消逐条审批的决定保持。用户授权的是功能开发，本轮不实际修改其 QQ 资料或发布测试动态，不调用收费云模型，不提交。

## 当前行为
QQ 已有发送文字/表情、拍一拍、看入站图片、收藏与备注表情，以及通用联网和记忆工具。缺少近期平台历史、引用原文读取、自身撤回、名片与资料管理、空间发布和无人聊天时的账号自主活动。托管组件固定 NapCat 4.18.42；该版本已提供所需空间与账号接口。

## 目标行为
1. 聊天互动增加：读取当前聊天最近消息、读取本轮引用或历史列出的消息；撤回当前聊天中由大肥鱼自身发送的消息；更改当前群自己的群名片；给当前发言人名片点赞、对当前聊天消息表情回应。所有参数绑定真实登录账号/当前聊天，不提供任意目标和任意 OneBot action。
2. 自身账号工具：读取自身昵称/签名等必要资料；修改自身昵称与签名（用户所说简介）；使用实际查看过且验证的图片更新头像；读取自己的最近说说；发布纯文字或带已验证图片的说说。空间名称/说明读写可在同一模块中补齐。省略的资料保持不变。
3. 全局账号资料和空间写工具仅向已验证的主人私聊及独立自主任务开放，普通好友/群友不能通过自称或引用指令更改账号。当前群自己的名片等局部互动仍限授权群；撤回只认真实消息发送者为自身，群管理员权限也不能扩成撤回别人。
4. 自主活动在 QQ 在线、账号授权有效且开启时定期判断，模型可以不操作；不要求用户每次明确索要。使用既有聊天模型、原完整人设和有限公开资料；不把主人/好友/群的私人聊天、长期记忆或整篇日记送入公开发布的自主上下文。可参考鱼自己的心情标签（无私人原因）和当前公开资料。历史说说正文无法充分证明可见范围，因此自主路径不读取；主人私聊仍保留最近动态查询，去重由持久指纹负责。自主头像只从已知内置素材选择，不能擅自把收到的私人图片设为公开头像。
5. 保持有限频率：默认每60分钟最多一次自主判断、每日最多6次模型判断/2条说说，头像/资料各有每日限额，重复内容不反复发布或更改；没有模型/未登录/关闭/暂停活动时不执行。不补跑关机期间所有任务。界面可关闭自主更新资料与自主发说说；说说默认好友可见，可选择仅自己或公开。模型不能扩大用户选择的可见范围。频率默认值在文档记录，不做满屏参数。
6. 写操作执行前重新核对账号、配置 revision、权限与取消状态；跨 await 后同样检查。持久化操作账本在网络请求前占位，超时/断线/崩溃标记结果待核实，不自动重发。存在实际回执才报已发布，资料更新可回读则核对；无法核实的头像等需如实说明服务确认边界，不能把发起请求等同生效。停止/退出/切换账号不重放旧写操作，重复模型调用不能造成同一操作重复发送。
7. UI 延续 beUI 与已有布局：QQ 内紧凑「自主活动」设置，支持关闭、说说可见范围，状态就近显示。消息页依然只有需要处理的问题，最多20条内部滚动，不重新塞入成功/开始等技术日志，也不增加审批入口。外部旧协议不支持时工具返回明确不可用，不能因未登录/等待扫码弹全局错误。
8. 新持久状态与现有备份兼容，恢复后暂停自主外部写动作，运行中任务不恢复重放。最少必要模块分层：平台协议适配、工具/权限、执行账本、自主调度和 UI；不把所有代码堆入 Channels 或 QQConnection，不引入新包体系。

## 非目标
本轮不加好友/处理申请、踢人、禁言、改他人名片、退出群、删除好友、通用执行任意平台 action 或系统文件读取；不重写 NapCat、不迁移为另一协议端、不创建新的账号登录流程。用户图片生成不在本轮范围，头像选用已有验证素材。

## 技术与验证边界
保持当前原版 NapCat；依据固定4.18.42接口实现，不把上游 main 新增能力当作固定版已有。真实账号、云模型与用户库不用于本轮验证。隔离 OneBot WebSocket/本地模型夹具应走实际工具注册、协议与执行路径，不能只有函数mock。必要时可用本地只读组件状态，但不得泄露凭据或更改真实会话。

## 验收
- [x] 互动工具确实出现在对应 QQ 回合并能通过实际协议调用；历史/引用/撤回严格限当前聊天和自身消息。
- [x] 自身资料、头像及说说读写协议正确，资料省略保持、可见范围固定、图片仅通过已验证字节传递。
- [x] 主人识别、普通好友/群隔离、撤权/停止/账号切换守卫有效；没有审批机制或任意 action 后门。
- [x] 自主判断能在无人发消息时触发并选择操作或休息，限额/去重/暂停/失败/重启行为有定向证据；不输入私人资料。
- [x] 写账本先于I/O，未知结果不自动重试，回执不完整不假报成功；恢复不重放。
- [x] UI 简洁、900/380宽度可用，错误就近、记录最多20条内部滚动；文档真实描述能力与未实发边界。
- [x] 相关 S3 检查与新的独立验收通过，不默认全仓库检查、不调用真实收费模型/外发、不提交。
