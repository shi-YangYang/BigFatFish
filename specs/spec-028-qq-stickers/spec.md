# Spec — QQ 表情回复

状态：Done（2026-11-05）。EXISTING，基线 f39d9cc，dev。

## 背景
用户发现 aigengtu.com/persona 的人设会调用表情工具，明确要求「加上啊」。当前 QQ 自动回复只有文字，手动发送已经支持 PNG/JPEG。

## 目标
让大肥鱼在 QQ 回复中按语境选用表情图片，用户可预览和管理自己的表情库。

## 非目标
不增加 AI 生图服务、任意网址抓图、任意收件人工具、其他平台发图或泛化插件权限。用户补充希望使用网络图片并可内置；本轮加入梗鲸公开图库，暂不做 QQ 收藏同步。

## 当前行为
Channels 经 ChatService/DSH 生成文字，再统一复核目标、账号、取消和记忆范围并发出。QQ 身份不能调用普通本地主人插件工具。图片只接受已验证的有界 base64。

## 目标行为
- QQ 页面增加紧凑的「表情」管理入口，预览内置图片，添加 PNG/JPEG、填写名称/适用场景、启停、删除自添加图片。
- 内置三张同一大肥鱼娘形象的表情：开心招呼、撒娇求夸、轻微赌气。root 负责生成和提供资源；不改应用图标。
- 默认可以自然使用启用的表情，但不强制每条发图；严肃问题优先文字；不输出伪装成图片的文字占位符。
- 支持「网络表情」开关；使用梗鲸固定公开索引按关键词选择少量候选，先查看实际图片再决定发送，网络不可用时正常文字/内置表情仍可使用。UI 显示简短来源链接。
- 模型可以列出可用表情、查看具体图片、选择当前回复的一张表情。实际发送由 QQ 回复生命周期统一完成，工具不得冒充已经发送成功。
- 即使空表情库或不选图，现有文字回复仍正常。合理支持仅表情回复或明确保证工具选择会附带自然简短文字，不能无声丢掉已选图片。

## 功能需求
1. 表情以不可猜测或稳定内部 ID 引用；模型只能选择当前启用库内图片。名称和场景有长度限制，文件单张不超过 2 MB、数量及总量有界。
2. 表情持久化，重启后保留；包含在相关逻辑备份范围，旧归档仍可恢复，不在用户真实数据目录执行验证。
3. 列表仅返回元数据；图片按需读取，预览通过现有认证 API，不把令牌放 URL。
4. 每次 QQ 回复最多一张图，不允许工具指定收件人、URL、本地路径或任意 base64。保持唯一主人、好友/群范围与记忆隔离。
5. 查看工具必须让聊天模型实际获得图片内容，不能只返回 metadata 却声称看图。DSH 若增加图像工具结果，仅可信声明的内部工具可用，普通插件结果不自动升级。
6. 选择在本轮内暂存，取消、失败、权限撤回、账号变化、表情删除/停用时不发送；发送前复核。沿用 confirmed/failed/unknown 状态与不自动重试规则，文本与图片结果准确审计。
7. 现有 local-owner 插件工具授权保持不变。调用上下文通过内部参数传入，不能由公共聊天请求伪造。
8. UI 使用已有 beUI 封装、浅海蓝、40px 控件、既有间距；中文短标签，窄屏无横向溢出，操作错误走现有短暂反馈。
9. 网络搜索仅固定 https://aigengtu.com/gallery-index.json 的 DeepSeek娘目录；图片仅固定 img.aigengtu.com 的已核实 meme 路径，输入不能指定任意URL。外部元数据视为不可信资料，禁止作为指令；限制下载/解码体积、像素、耗时和每轮数量，禁止重定向与非公网地址，缓存有界，取消和关闭网络源阻止尚未发送的图。
10. 网络图片按 WebP 解码并转换成已有 PNG 出站格式；选择前必须本轮实际查看，不因目录名称而伪称识图。避免色情/露骨及与当前语境不适合的内容，保持默认女儿感日常交流。普通工具结果不能借用图像包装提权。

## 边界条件
校验空/大/伪造图片、无效 ID、已禁用图片、重复选择、被取消任务、工具失败、QQ 不在线、发送中断与 unknown；非法选择不能扩大权限或替代为任意文件发送。

## 技术约束
沿用普通源模块，不分包、不新增泛化服务。固定 DSH 0.2.2-alpha.2；不修改 NapCat 源码。内置素材必须包含在 Node 产物及发行资源。不得真实发送 QQ 或调用收费模型来验收。

## 兼容性要求
已有设置和账号不被覆盖；原有聊天/主动文字和手动媒体路径保持；存储升级必须可用于原数据库和旧归档。现有默认女儿感与自定义人格保持。

## 验收标准
- [x] 启用表情可列出、真实查看、按当前聊天语境选用并以 QQ 图片段发出。
- [x] 文字-only、无表情和失败路径正常，未选择时不强制发图。
- [x] 回复取消、目标/记忆权限变更、图停用/删除及无效 ID 均阻止越权发送；无重复/未知结果重放。
- [x] 库增删启停、限制、持久化、旧归档兼容与新备份保留得到定向验证。
- [x] 真实 DSH + 本地模型/OneBot fixture 验证看图与选图链路，不冒充真实 QQ/云模型验证。
- [x] 桌面/窄屏管理界面可用，三张内置图随构建分发，用户自定义设置不改写。
- [x] 网络检索、真实图像读取、限流/大小/非公网拒绝/失效来源/关闭取消由本地 fixture 验证；不依赖真实网站完成测试。
- [x] 新的独立 Agent 验收 PASS，按持续授权本地 commit；不 push。
