# 实施与验证

为已确认事实建立场景归纳、持久化及增量更新，保存独立的场景标识、摘要与证据关联。聊天按话题和当前受众检索，管理页面按归属呈现场景和原话。人物资料可从相关证据追溯至场景。

本次涉及持久化、备份兼容和公开会话隐私，按 S3 验证。针对场景跨回合合并、无关事实隔离、修正/删除和备份恢复测试，用真实模型验证重启后的新会话，再独立审查。此次授权为实现与真实验证，本地 Git 提交另按用户指示。

## 实施与验证结果

SQLite schema 12 根据已确认的 L1 维护场景主题、摘要和参与归纳的事实。升级及归档恢复按事实重建索引，再逐个主题归纳。对明确指向上一项活动的简称保留依据，来源失效会影响该关联。场景查询优先看本轮话题，也可利用已经启用的本机语义检索。没有独立依据的单条事实不会为了凑层数生成场景。

在 Chromium 验证从「场景记忆」打开关联事实和原话，以及从人物资料打开相关场景。模拟 OneBot 验证群里两人的贡献和在途撤销。真实百炼测试首次检出预订物资漏记、改期未更新和场景归并失效；修复后使用同样五条输入，跨两个写入会话、重启后的空会话、SQLite、管理接口和云端请求中的摘要均核对。[真实测试](live.md)

独立验收发现的语义命中接线、长句截断和单发言人群场景归属已修复，新增验收员[复验通过](acceptance-r1.md)。未重启用户当前实例，本轮改动留在工作区。
