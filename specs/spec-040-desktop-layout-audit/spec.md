# Spec — Desktop 全页面布局修复

## 背景
用户反馈绝大部分 Desktop 页面排版存在错位、重叠与不一致，要求分别安排排查和设计 Agent，最终修复全部页面并尽量覆盖元素级。当前 dev/06d299d，工作区干净；已有浅海蓝、beUI 与简洁桌面 WebUI 方向继续有效。

## 目标
逐页、逐状态识别与修复布局问题，形成统一可用的页面、卡片、表单、操作区和浮层；以实际渲染证据证明完成，不以旧验收或少数截图代表全部页面。

## 非目标
不增加/删除业务功能，不更换品牌/框架/UI库，不改后端协议或真实账号配置，不发送消息或触发付费模型，不自动 commit/push。

## 当前行为
共享样式包含全局 form/fieldset/.settings、卡片 margin 与 beUI 原语规则；页面独立排列标题、状态、按钮、表单和嵌套卡片。具体失败由本轮新截图和元素几何记录确认，旧 Spec037 证据仅作定位参考。

## 目标行为
浅海蓝和现有导航基础下，所有页面布局清楚、对齐一致、无元素覆盖/裁切、无非预期横向滚动。常规按钮/输入统一40px，图标按钮方形；按内容区分主要/次要操作，不机械强制所有内容等高。窄窗自然换行与堆叠，局部列表在卡片内滚动，浮层可见可操作。

## 功能需求
1. 覆盖聊天/历史/声音浮层/运行菜单/审批抽屉、初始引导/离线状态；我的鱼概览/设定/记忆/经历/活动计划；连接总览、QQ回复设置/表情/操作记录/连接选项、B站各页签、抖音各页签；设置模型/扩展/声音/通用/数据/关于/高级及 Web 差异页。
2. 不仅默认空态：覆盖有内容列表、长名称/长文、表单展开与编辑、选择器/折叠/确认操作、加载/禁用/错误/成功等直接布局状态。以页面矩阵记录哪些状态实际检查及发现问题，缺项不得称完整。
3. 统一内容宽度、标题层级、字段间距、卡片内边距、状态与按钮区域对齐；消除因全局选择器或嵌套 margin/gap 引发的重复留白/尺寸污染。
4. 可调整前端组件结构与共享布局封装以恢复清晰职责，保留事件、状态、草稿、保存与滚动边界；不通过隐藏关键功能或裁切内容掩盖溢出。
5. 每项确认问题有明确修复位置与新渲染复查；覆盖900×680常见窗口、1280×800宽窗、640×720窄窗和380×820 Web响应，低高浮层按需要加测。原生截图与浏览器fixture分别标注，不能相互冒充。

## 边界条件
真实 Desktop 只读浏览，不清空/保存用户配置或执行连接/平台写操作；编辑/错误/首次使用等危险或难以稳定构造的状态用隔离真实组件 fixture。不要停止现有 Runtime/QQ；必要时仅打开额外审计 UI。

## 技术约束
同一个实施 Agent 串行改共享样式和相关页面，排查/设计阶段可并行且不写业务代码。保留beUI普通源码组件，不分包。S2：跨多个前端组件和共享样式；用户明确要求全页面验证，允许针对所有页面做浏览器布局/交互检查及原生截图，非全仓库后端测试。

## 兼容性要求
Desktop/Web共用组件一致，键盘焦点/可访问名称、正常与减少动画模式、内容滚动不受损；当前用户数据/人设/模型/QQ配置保持。

## 验收标准
- [x] 本轮全页面与关键状态矩阵、问题清单及完整after齐备；before原图损失及保留范围在Plan中如实记录，不把覆盖图当原图。
- [x] 已确认错位/重叠/裁切/溢出问题全部关闭，核心控件和表单间距一致。
- [x] 所有页面在指定宽度实际检查，关键浮层/长内容/表单状态正确。
- [x] 实际原生Desktop逐页截图复查通过；原生与fixture分别记录，登录/危险操作等隔离状态不冒充实机外部行为。
- [x] 相关前端检查及必要交互回归通过，新独立验收PASS，无直接未解决问题。
- [x] 无真实配置/外发副作用，无未授权Git操作，必要验证后停止。

## 待确认问题
无新的产品方向缺项。以用户已确定浅海蓝/beUI/简洁WebUI为基础；布局方案依据本轮排查细化，不扩业务范围。
