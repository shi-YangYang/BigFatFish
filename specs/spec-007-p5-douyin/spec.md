# Spec 007: P5 抖音观看与互动

状态：本地代码验收PASS，完整P5尚未完成。全部已复现本地缺陷经新实施/独立复验闭环，原生Mac已有操作证据。私信/分享/上传发布wire仍未确认而拒绝；真实账号/云/Windows/Linux图形仍未验证。专用浏览器HTTP/HTTPS直连、不继承系统代理，限制已公开。按用户授权本地提交可验收结果后继续P6。

## 背景

用户要求整合 LockyBee/dsh-douyin-agent 和 kdcadmin/dsh_douyin_tools。前者当前发布版本仅声明 Windows/Edge，后者提供真实 Python MCP；不能将两个独立浏览器、调度和记忆系统直接并排运行。

## 目标

以统一浏览器管理、任务队列、人格和记忆，复用两上游的观看采样与互动能力，完成视频观看/理解、兴趣与经历、互动审批、任务调度及真实状态展示。

## 非目标

不绕过登录、验证码、风控或访问限制，不自动读取现有浏览器 Cookie，不假称 Windows 专用实现已支持 macOS/Linux。不让插件自行调用另一套模型或写另一套记忆；不以开启环境变量代替权限审批。

## 当前行为

仅有固定上游版本、许可、真实接口与兼容限制研究。LockyBee 有 DSH 工具和本机 HTTP/BrowserController；kdcadmin 有 Python FastMCP stdio、浏览器和可选 ASR 依赖。尚无本产品浏览器管理或抖音插件。

## 目标行为

用户明确连接/登录专用浏览器会话，观看和互动排入同一队列；当前任务可暂停/取消。读取结果、视频证据和理解进入统一活动与兴趣。点赞、评论、私信、发布先呈现实际目标与内容审批，未经批准绝不发出对应操作。

## 功能需求

1. 固定两上游版本并保留许可/NOTICE/补丁记录，分别复用已有能力。先核实实际入口、数据位置和共享浏览器能力，必要平台适配以明确补丁实现，不能仅在文档提到上游而用空壳冒充整合。
2. Browser Manager 统一拥有独立 profile、账号会话、连接和生命周期；观看/互动的同一账号任务串行获取浏览器使用权。若上游无法直接接入同一个受控浏览器，必须先做可验证适配；不得同时启动争抢账号状态的两套控制器。
3. 浏览器配置、授权和登录由用户明确操作，保存于本产品数据目录；支持实际可用的浏览器发现/显式路径及诊断。云端无界面环境的登录限制准确说明；登录失效/验证码等转入需要用户处理的状态并停止相关动作。
4. kdcadmin 通过真实 Python MCP stdio 调用，完成 initialize/initialized/tools list/call，显式工具名单，避免空 DOUYIN_MCP_TOOLS 放开上游 memory_*。写工具可见性与执行权限分开，DOUYIN_ALLOW_WRITES 不构成审批；如使用宿主代理，鉴权与调用绑定经测试。
5. LockyBee 的观看/采样能力通过其真实接口或经记录的必要适配接入，明确其原 Windows/Edge 限制。统一输入输出、任务取消、超时和收据，不直接加载独立大脑、自动互动服务或其全局配置。
6. 搜索、推荐流、视频详情/评论、观看与采样有真实结果校验；视频去重和采样预算明确，只有实际取得的字幕/画面/音频才能作为理解证据。统一视觉/ASR路由按实际能力工作；未配置模型、缺依赖、无字幕或仅部分证据时返回具体状态，不生成假理解。
7. 结果包含来源、视频/作者标识、时间、所用证据和模型结论。事实观察与推测分开，进入同一经历、兴趣、记忆和日记，不复制上游独立SQLite记忆；重投事件幂等。
8. Permission/Approval 服务持久化实际操作、账号、目标、正文、内容摘要/版本、到期时间与审批人。审批绑定不可变操作；参数变化、账号变化、过期或撤销必须重新审批。点赞/评论/私信默认人工批准，发布/删除/账号修改必须批准。
9. 只有通过权限与审批的单次动作才能入执行队列；执行前再次核对，完成/失败/未知结果进入审计。平台超时或页面变化不能盲目重试写操作，不能把点击动作当发布成功；取消或撤销后阻止尚未发出的动作。
10. 统一调度支持用户设置的观看活动、时间规则、启停、并发限制与历史；默认不启用未授权自主任务。重启后恢复任务记录，防止过期/重复任务集中执行；全局暂停和插件禁用停止新任务与自动重试。
    同一调度也接入P4的B站观看活动，补齐产品自主浏览目标；不在B站/抖音各建独立定时器或大脑。
    用户显式启用自主模式后，同一Agent可依据已确认兴趣与当前状态选择获准的只读活动；决策、任务和结果可追踪，并有调用/时间预算。区分Conversation/Activity/Autonomous/Scheduled，不能把固定计时器或随机数据描述为自主决策；写操作仍必须审批。
    自主浏览允许在用户授权的平台/主题范围内通过实际搜索或推荐流发现有界候选，再由Agent决定观看或跳过；固定视频清单可用于定时任务，但不能成为自主浏览的唯一来源，避免看完后永久只返回去重记录。发现、选择和观看共享预算与来源记录。
11. Desktop Channels/Tasks/Permissions/Life 与 CLI 真实管理浏览器、观看、队列、调度、审批和结果；Home当前活动同步统一任务，不能在B站/抖音观看时显示空闲，并复用平台连接及待审批入口。不向界面或日志泄露 Cookie、token、完整浏览器调试凭据。

## 边界条件

页面变化、缺登录/验证码、浏览器崩溃、超时、两个模块同时请求浏览器、同视频重复、取消后的迟到响应、审批参数被替换、待执行时撤销、重启恢复、未知发布结果、视觉/ASR失败、依赖安装失败、账号更换和平台限流。

## 技术约束

复用 Python 辅助服务而不无理由重写。独立子进程和受限 RPC 不等于 OS 沙箱，权限检查属于 Runtime。上游 npm 缺失项目按固定Git源码安装，不能编造已发布包。模型、人格、记忆、事件、任务和审批保持统一。

## 兼容性要求

支持证据按 Windows/macOS/Linux 分别记录；不支持的平台/浏览器显示明确状态，不退回未经授权的其他会话。插件停止或依赖不可用不影响其他入口；既有 P3/P4 任务和审批语义保持一致。
