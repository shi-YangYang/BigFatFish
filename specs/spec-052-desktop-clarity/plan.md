# 实施与检查记录

S2：共享控件、样式及相关前端页面交互。验证以原生逐页检查、受影响前端定向检查为主；不运行后端全套测试。

1. 协调 Agent 操作原生 Desktop，建立页面问题清单并参考 Apple HIG / Fluent 2 的中性色、交互与层次指南。
2. 一个实施 Agent 串行调整共享配色/控件、人设页、模型编辑流程，并修复巡查直接发现的同类问题。
3. 协调 Agent 在当前代码原生窗口复查；隔离夹具补充不宜操作真实账号的状态，相关前端检查只跑一次，失败或改动才重跑。
4. 新独立验收 Agent 对照 Spec、diff 与原生证据判断，发现阻塞项再返工。

参考：[Apple Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Apple UI Design](https://developer.apple.com/design/tips/)、[Fluent Color](https://fluent2.microsoft.design/color)。采用中性内容面、克制品牌色、清晰就近操作，不复制平台专属玻璃效果。

## 实施结果与最终复查

- 灰白层级、蓝色重点与平台语义状态完成；输入仅由外层字段绘制焦点，按钮不再点击缩放。
- 人设保留名字、两张完整卡与自定义面板；删除零散详细字段入口但保存仍保留原值。模型明确编辑，未修改不产生草稿入口，已有草稿切换前提示。
- 记忆编辑/整理/设置和活动创建使用独立面板；插件信息按需打开；声音区分输入与朗读，缺模型直接进入模型设置；通用页的数据目录为只读信息。
- 备份/恢复分模式；更新默认版本与检查，来源和离线按需打开；诊断入口命名明确。B站记录选择后分享，抖音未连接互动提供连接下一步。
