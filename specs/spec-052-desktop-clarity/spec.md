# Desktop 清晰度与易用性

状态：Done（2026-11-07）。[最终独立复验 PASS](acceptance-r1.md)。

## 背景
用户指出全界面淡蓝色导致层次弱、输入框焦点重复描边、人设详细字段冗余，以及模型条目点击后位置和身份变化。要求直接操作原生 Desktop 逐页检查，参考成熟桌面设计并修复。

## 目标与目标行为
面向普通用户，让聊天、我的鱼、连接、设置中的内容、表单、导航与操作可区分，路径稳定且必要动作明确。

## 当前行为
蓝色同时用于边框、次要文字、背景、选中和交互；输入组件自身 ring 与全局 input outline 叠加；人设同时提供完整卡与零散详细字段；模型编辑内联插入列表上方并滚动焦点，模型名称伪装成标题。

## 功能需求
- 采用中性底色、白色内容面、灰色边框与深色文字；保留大肥鱼蓝用于品牌、主要动作与选中状态；错误/成功等使用独立语义。
- 统一控件 hover / pressed / focus，输入框只保留一套清晰轻量焦点，键盘访问仍可辨识。
- 删除人设页「编辑详细设定」及头像 URL / 行为边界 / 作息等零散字段入口；保留名字、两张完整人设卡、必要的完整人设自定义能力。保存不得清空用户已有底层字段。
- 模型列表使用明确「编辑」操作和稳定的编辑界面，关闭后返回原位置；避免点击条目后原位置变成标题或布局跳动。保留配置、默认用途、测试和发现能力。
- 实际巡查全部一级页与其子页，修复同类视觉、布局和直接交互问题，减少重复标题、嵌套卡片、无意义常驻说明及过多折叠。
- 巡查发现的直接路径：扩展以名称/状态/操作为主，技术资料按需打开；声音区分语音输入与朗读，缺少模型时提供设置入口；通用以运行开关为主，数据路径只读；备份与恢复分开，更新默认展示版本/检查动作；日志入口明确叫诊断。
- 记忆编辑/整理与计划创建采用稳定面板，记忆筛选和本机检索设置按需展开；记录页默认呈现记录，B站分享在选择记录后配置对象；连接状态用统一语义色，未连接时明确下一步。

## 边界与技术约束
沿用 React / beUI 与既有目录。只修改前端及直接相关使用说明，不重构记忆/权限/平台业务，不删除用户数据，不替换完整人设来源。检查真实界面不执行外发、删除或保存账号配置。需要有数据/空态等覆盖时使用隔离夹具。用户随后明确授权本轮本地 commit，完成必要验证和独立验收后提交；不 push。
