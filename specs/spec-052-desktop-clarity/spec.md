# Desktop 清晰度与易用性

状态：Done（2026-11-07）。[最终独立复验 PASS](acceptance-r1.md)。

## 背景
用户指出全界面淡蓝色导致层次弱、输入框焦点重复描边、人设详细字段冗余，以及模型条目点击后位置和身份变化。要求直接操作原生 Desktop 逐页检查，参考成熟桌面设计并修复。

## 目标与目标行为
面向普通用户，让聊天、我的鱼、连接、设置中的内容、表单、导航与操作可区分，路径稳定且必要动作明确。

## 当前行为
蓝色同时用于边框、次要文字、背景、选中和交互；输入组件自身 ring 与全局 input outline 叠加；人设同时提供完整卡与零散详细字段；模型编辑内联插入列表上方并滚动焦点，模型名称伪装成标题。

## 功能需求
- 采用中性底色、白色内容面、灰色边框与深色文字；保留大肥鱼蓝用于品牌、主要动作与选中状态；错误/成功等使用独立语义。
- 统一控件 hover / pressed / focus，输入框只保留一套清晰轻量焦点，键盘访问仍可辨识。
- 删除人设页「编辑详细设定」及头像 URL / 行为边界 / 作息等零散字段入口；保留名字、两张完整人设卡、必要的完整人设自定义能力。保存不得清空用户已有底层字段。
- 模型列表使用明确「编辑」操作和稳定的编辑界面，关闭后返回原位置；避免点击条目后原位置变成标题或布局跳动。保留选择模型、配置、测试和发现能力。
- 实际巡查全部一级页与其子页，修复同类视觉、布局和直接交互问题，减少重复标题、嵌套卡片、无意义常驻说明及过多折叠。
- 巡查发现的直接路径：扩展以名称/状态/操作为主，技术资料按需打开；声音区分语音输入与朗读，缺少模型时提供设置入口；通用以运行开关为主，数据路径只读；备份与恢复分开，更新默认展示版本/检查动作；日志入口明确叫诊断。
- 记忆编辑/整理与计划创建采用稳定面板，记忆筛选和本机检索设置按需展开；记录页默认呈现记录，B站分享在选择记录后配置对象；连接状态用统一语义色，未连接时明确下一步。

## 边界与技术约束
沿用 React / beUI 与既有目录。最初的视觉整改限于前端及使用说明；后续任务流程调整有两处例外：Runtime 支持为本地对话更换模型，原生宿主引入 `rfd` 选择备份文件。均不改变数据库结构。不重构记忆/权限/平台业务，不删除用户数据，不替换完整人设来源。账号、空态和外发路径使用隔离夹具检查，不对真实账号执行操作。

## 非目标与待确认问题
不增加主题选择器或新 UI 库，不改变已有平台授权范围。

## 全页面组件化改版

覆盖聊天和历史、我的鱼各分区、连接首页及三个平台详情、设置七个分区和首次设置。按阅读、浏览、配置三类任务分别排版；导航只出现一次，表单对齐，正常等待不报错。沿用 beUI 控件，把重复的分区标题、操作区、内容面板和空状态抽成共用组件，不增加 UI 库。

保留现有业务、权限和危险操作确认。验收覆盖宽窗及窄窗、键盘可访问性和实际页面状态；只用隔离数据，不扫码、不调用收费模型，不改正在使用的账号或配置。

## 按用户任务简化流程

- 首次设置采用默认值，允许更改。聊天和声音按原用途直接配置模型；保存后继续原任务，不自动发送付费测试。历史对话缺失模型时可以修复，不丢消息或草稿。
- 概览只展示鱼的近况，不重复放「最近经历」或笼统的「兴趣与关系」。经历只读活动时间线；日记是「我的鱼」的独立分区，可以阅读、补写和调整写作时间。记忆以最近记住的事为主，区分空库、没有搜索结果和读取失败；维护工具仍可用，四层记忆和隐私范围不变。
- QQ 按连接、选择回复对象、已配置三个阶段呈现；登录与自动回复分别说明。普通扫码、外部服务、账号授权、表情与自主活动均保留，消息区只展示需处理的操作记录。
- B站具名提供匿名浏览，抖音未启用时先引导连接。已连接的空记录可直接创建对应平台的计划；不自动保存或观看。B站的分享目标从 QQ 当前授权范围中选择，并仍由服务端校验。
- 保留四个主入口；设置按「模型与声音、通用、数据与维护」呈现，保留扩展、更新和诊断；桌面备份导出/恢复使用系统文件选择器，保留危险操作确认和加密选项。
- 「模型与声音」只列文本、语音输入、朗读三个用途与当前选择；进入哪个面板就在哪个面板选择或添加模型，不另设「默认用途」或重复的语音设置。新建文本模型先选服务商，再填密钥、选模型；保留已有配置，不替用户改计费方式或自动测试。观看计划先选「按兴趣看／看指定视频」，再填主题或对应平台的视频。QQ 扫码后首次启用显示「保存并开始回复」，关闭自动回复或编辑已有范围时显示「保存设置」。

## 产品入口

桌面 Tauri 窗口内的 WebView 是唯一图形界面。独立网页版、网页登录、HTTPS 网关及对应的构建、打包和 CLI 子命令均移除。Linux 无界面部署继续使用 Runtime 和 CLI；普通浏览器仅用于开发预览或隔离测试。

验收边界：桌面界面可以构建，原生 IPC 和本地流式聊天路径保留；独立网页及网关不进入发行产物或命令入口，普通网页拿不到本机认证或数据。保留既有用户数据，不把抖音专用浏览器、NapCat WebUI、联网工具当作网页版删除。

## 桌面留白与操作精简

- 聊天工具栏从工作区边缘起排，不随正文的阅读宽度向中间漂移。历史图标与标题协调，点击区域和键盘入口保留。空白对话不重复提供无效的新建动作。
- 连接详情的返回动作使用独立箭头和文字，留出左右内距。QQ 桌面只引导单账号扫码；不再显示选择服务或切换方式的菜单。不改变已保存的登录、主人和回复权限。只含一个动作的菜单不必先展开。
- 日记设置的开关、时间/时区与操作区分组排列，保存按钮不紧贴输入框；不因打开或关闭抽屉改变既有设置。保留自定时区及费用提示。
- 降低普通页面与卡片的区块间距，表单仍保留读写所需间隔。优先移除重复文案、无效动作和仅有一项的中间菜单；不合并含义不同的「断开」与「暂停回复」，不取消危险操作确认。
- 用普通桌面、宽桌面与窄窗对照聊天、已有 QQ 连接及真实日记抽屉，并用隔离数据确认权限、保存与返回行为，不使用真实平台账号。
