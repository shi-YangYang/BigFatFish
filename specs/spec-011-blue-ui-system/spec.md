# Spec：DeepSeek 蓝色主题与统一前端组件

## 背景

用户指出上一版配色不符合大肥鱼的 DeepSeek 蓝色形象，且仍有明显的对齐和组件大小不一致；允许使用 UI 库或手动封装，如用库推荐 beUI。本轮为 Spec 010 后续的视觉与组件修正，Done（独立返工复验 PASS）。

## 目标

使用 DeepSeek 蓝色主题，建立并实际使用普通源码 UI 组件，消除同类控件尺寸、字段排列和操作行对齐不一致。保留已有导航与业务行为。

## 非目标

不重新设计信息架构，不新增平台/Runtime API，不改变审批、认证、数据或聊天请求契约，不换框架或分包，不重做鲸鱼娘素材。

## 当前行为

共享 style.css 以绿色为主，许多业务页直接写 button/input/select/label；全局元素规则和页面覆盖共同控制尺寸。已有 UI.tsx 仅提供头像、图标、Tabs、Drawer，尚未统一基础表单与动作组件，之前验收主要覆盖聊天与模型默认视图，平台详情/复杂表单缺少几何核对。

## 目标行为

1. 以官方官网样式中的 `#4D6BFE` 品牌蓝为基础，配白色与浅蓝灰中性色；主操作、选中态、链接、焦点统一，状态色保留语义。
2. 手动封装并在现有业务页使用 Button、Input、Select、Textarea、Checkbox、Field，以及确有复用的操作行/表单网格。保持普通源码，不创建包。
3. 同一类常规按钮、输入、下拉统一40px；图标操作统一40px。紧凑文字动作可显式使用32px，但同一表单操作行不得混入意外尺寸。多行文本、列表项和多行内容按实际语义扩展。
4. 字段标签、输入边缘、帮助/错误文本和底部操作共用对齐基线。行内输入+操作按钮底部对齐；复选项与文字垂直居中；长标签/长路径/窄屏可以自然换行而不重叠。
5. 聊天、我的鱼各子页、连接列表与QQ/B站/抖音详情、设置各子页、审批Drawer、Web登录共用相同视觉规则；改变外观不影响已实现功能。

## 功能需求

- 基础控件支持原有属性、受控值、ref、disabled、原生验证、键盘与可访问名称；表单提交按钮显式保留submit语义，不因默认type改变丢失提交。
- 使用明确组件变体替代隐含的 CSS 属性/祖先选择器决定主按钮外观。优先删除被替代的冲突规则，避免尾部继续堆覆盖。
- 不只更换首页颜色：复杂表单与次级页必须实际查看。内容、审批风险提示、只读/未知结果、恢复确认均保留。

## 边界条件

无内容、禁用/忙碌/错误、长中文标签和长路径；窄窗口以及审批模态。保留 Spec 010 的会话草稿与请求所有权、抽屉内错误和原宿主能力边界。

## 技术约束

已核实 beui.dev 是基于 React/Tailwind4/Motion 的按源码安装组件库。当前工程无 Tailwind/Motion；用户明确允许手动封装，本轮据此使用本地原生语义组件，避免为纯尺寸/排版问题迁移样式工具链。不复制 beUI 源码，不声称已接入该库，也不安装无关替代库。后续若明确要求 beUI，可独立评估接入。

## 兼容性要求

Desktop/Web 同一套组件；现有 API、状态与事件处理保留。已配置人格头像和其他数据不改动。新视觉不要求用户迁移数据。

## 验收标准

- [x] 主要交互颜色统一为 DeepSeek 蓝及衍生色，无残留绿色品牌态（成功状态除外）。
- [x] 公共基础控件实际覆盖业务页，常规控件40px；主按钮type/disabled/事件和输入可访问语义保持。
- [x] 模型/人格/记忆、QQ/B站/抖音、插件/通用/数据/声音、审批与Web登录的表单/操作行对齐，无重叠或意外拉伸。
- [x] 1100×760、820×760、640×760代表页面无横向溢出；聊天发送可见，字段和按钮的几何检查与截图相符。
- [x] 必要的共享UI类型/构建与已有定向交互检查通过；独立视觉/代码验收不只依赖测试文字报告。

## 待确认问题

无阻塞项；本轮选择用户已允许的手动封装。用户持续授权阶段完成后本地commit，无push或发布。
