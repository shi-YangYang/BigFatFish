# Spec：大肥鱼蓝色主题去紫

## 背景
用户明确要求UI换成大肥鱼蓝色系，否决当前偏紫观感。dev基线cfa2953，开始干净，无需重复空提交。本Spec Done，新独立验收PASS；最新用户要求取代此前靛蓝主色选值。
## 目标
主按钮、页签、导航选中、checkbox、浅底、焦点及聊天气泡统一为清晰的纯蓝与浅蓝。
## 非目标
不改布局、间距、控件尺寸、业务、依赖或头像素材；不把警告/成功/错误语义色全部染蓝，不重打发行包。
## 当前行为
style.css主色#3959e4/品牌#4d6bfe、浅底#eef2ff及焦点#a8b8ff偏靛紫；beui-theme.css还重复硬编码浅底/焦点，单改主色不能完整覆盖。
## 目标行为
主色#0866E6，hover用同系深蓝，选中浅底#EAF4FF，焦点用浅天蓝；全套语义token在style.css归一并由beUI映射引用。选择文本、历史选中次要字、输入区边框及侧栏浅底同步去紫。蓝白配色来自用户当前视觉选择，不宣称是DeepSeek官方固定色号。
## 功能需求
只修改现有颜色定义/引用，覆盖主色及相关浅底/边框/焦点的同根因路径；保留真实状态色及必要中性色。白色主按钮文字应保持可读。
## 边界条件
默认/选中/悬停/焦点/禁用；beUI表单及聊天使用同套token；状态警告仍易区分。
## 技术约束
现有style.css与beui-theme.css；不升级依赖或重写组件。不得靠叠加新覆盖层保留旧紫色token来源。
## 兼容性要求
Desktop/Web共用样式；Spec016间距、40px控件与原有交互保持。
## 验收标准
- [x] 主色、浅底、焦点和beUI主题一致去紫，相关硬编码已归一。
- [x] 主按钮白字可读，错误/警告/成功颜色保留；无布局/逻辑改动。
- [x] 当前生产组件预览中模型页与含checkbox/聊天代表状态目视为蓝色；新的独立验收PASS。
- [x] 按持续授权本地commit，未push，未重打包的边界清楚。
## 待确认问题
无，用户已明确否决偏紫配色，具体蓝色为可逆设计细节。
