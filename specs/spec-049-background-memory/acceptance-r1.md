# Spec049 返工独立复验

**PASS。** 首轮验收的两项问题已关闭。

- **私聊更正群里提过的安排。** 单句和多句的明确改期都查询同人、同主题且在本场合可见的安排。写入事务核对当前候选与版本。临时库回归从真实分析入口处理群里的「周一复诊」和桌面的「改到周三」，主人只查到周三，原群仍为周一，另一群查不到。原群后来公开改到周五，主人也能查到周五。两个群各有一场复诊时，只凭「我的复诊改到周三」会跳过更正。分析期间旧记录被人工修改或删除，也会放弃写入。
- **同条消息两次指定称呼。** 写入前按人物记忆的类别和主题归并本轮更正，依照原话顺序选定最后一次称呼。实际分析入口的回归中，最终称呼「阿洋」关联「以后叫我阿洋」的原话，同条消息里的乌龙茶偏好也有独立记录。下一轮改叫「阿澈」成功，两个回合各自保留相应引文。

复验核对了分析器、写入事务、按受众召回的查询和回归断言。复用返工后分析器 11 项、写入与归属 10 项的通过结果。其余范围沿用[首轮验收](acceptance.md)。
