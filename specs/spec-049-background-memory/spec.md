# 回复后的记忆整理

大肥鱼先完成聊天回复，再按消息顺序整理长期记忆。桌面、Web 和获准的 QQ 对话共用这套流程。无需用户确认。新消息若早于后台完成，仍可能读到旧记忆。B 站、抖音的观看经历沿用现有流程。

## 如何取舍

1. 从本轮真实用户原话中挑选值得下次使用的陈述。允许一句也没有，也允许一条消息包含多件事。稳定偏好、明确指令和已确定的安排可保留，试探、引用、临时心情和拒记内容应跳过。
2. 按发言人、当前场合和话题查找已有记忆。可以参考有限的前文来理解省略的主语和事件。群内不能使用主人私聊、别的群或别人的私聊材料。
3. 对照已有记录，决定新建、更正、去重或跳过。写入要能追到真实原话。所指不清的更正应跳过，不能覆盖人工修改。处理期间身份、授权、来源或目标有变，写入前重新核实。

明确的单句继续使用本机规则。复杂表达使用现有聊天模型，检索沿用关键词与可选的 BGE small INT8。后台模型无权调用聊天工具或决定发言人、受众。

## 队列与验收

- 完成本地回合或确认 QQ 成功投递、授权静默时记录待处理任务。失败、取消、来源不可信的输入不产生个人记忆，旧聊天不批量入队。
- SQLite 持久化任务，同一 Runtime 逐条处理，有限重试且重启可继续。重复投递、重试或结果提交中断不能产生重复写入。
- 使用临时库和受控模型检验慢分析时仍能收发下一条聊天，核对多事实、含混更正、人物和群的隔离、人工编辑，以及版本升级的兼容性。验证不调用用户的真实模型和平台账号。
