# 实施计划

1. 独立的视频经历读取模块仅查询现有 SQLite：`new PlatformScenes(db).recall(query, { platform?, recent?, limit?, excludeSourceId? })`，返回有来源、时间、平台及有界摘要的数组。只取 B站、抖音真实观看；允许关联同一主题的多条证据，不能取聊天日志或兴趣候选冒充观看。该模块自身不拼装模型提示、不判断权限。
2. 聊天/视频编排集中组装受众和预算受限的上下文。可信身份由本机入口、QQ 配置及事件作者产生；模型不可补填权限。受众先于检索。对笔记、原子记忆、场景和画像使用不同的选取规则，不单靠全文搜索或最近几条。
3. 独立的 `OwnerLearning(db, memories).capture({messageId,author,text}, mode)` 只负责新回合的、有来源的主人自述，复核已完成消息、会话身份和来源。聊天编排负责筛选私聊/本机原文及调用时机；采用已确认的偏好留存策略。保护来源、冲突、纠正/遗忘和原有权限，不导入实机旧消息。更新直接相关的用户文档。
4. S3（身份、可见性与有来源的持久化事实）。用隔离数据测试写入→新会话→模型上下文、相邻群/好友仿冒、撤销、观看事件与虚假推测。生产类型检查和相关既有回归按风险选择。不操作真实账户，不提交。

## 模块实施记录
- `OwnerLearning` 从完整的、已完成的本人原文回合提取简短中文称呼、姓名、喜欢/不喜欢。不从一般推断、转述、假设或语音/图像识别提升为确认事实。已经人工编辑过的矛盾记录保留给用户处理。临时 SQLite 定向测试 4 项通过，覆盖来源、去重、纠正/拒绝/删除及换绑隔离。
- `PlatformScenes` 按实际观看事件的标题和理解摘要寻找话题，或按时间返回最近经历；可限定平台和排除当前视频。无近期词或话题不符时不会拿无关经历充数。定向测试覆盖超过 1000 条干扰记录、常用中文问句、平台过滤、来源字段与上下文长度。
- 聊天编排在主人私聊加入可见的核心画像，群聊仅识别发言人、召回本群笔记与公开事实；自主挑选和视频理解仅取鱼的兴趣、心情或相关观看证据。桌面上传音频生成的转写草稿有单独的来源标记，不作为直接书面声明。没有新增依赖、数据表、外部 API 或后台任务。
- `tests/integration/layered-memory.test.ts`、`tests/integration/qq-rework.test.ts` 和 `apps/runtime/src/memory/platform-scenes.test.ts` 合计 5 项通过；另有 4 项人设/记忆链路回归通过。`tsc -p tsconfig.node.json --noEmit` 通过，仓库 `tsc -p tsconfig.json` 仍有既有测试类型错误。使用隔离数据库、本地 OneBot 和模型夹具，未测试真实 QQ 投递或真实视频账号。
