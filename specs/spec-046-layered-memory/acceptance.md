## Issues / Required Rework
1. **换绑后的主人私聊笔记仍被普通好友召回。** `channels/service.ts` 中对话 ID 已随 revision 变更，但传给自动场景和笔记工具的 scope 固定为账号/类型/对端。A 改为普通允许好友后，新的好友会话可以收到 A 在主人身份时留下的私人笔记，工具也能查询或删除这些笔记。需要以可信关系隔离私聊笔记的所有读写，并兼容已有带作者的笔记。用换绑后旧主人作为普通好友发言验证，正常的群内共享笔记须保留。
2. **普通换话题会清空同群上一轮上下文。** `ai/chat.ts` 将随查询变化的 `sceneContext` 放入公开会话的 hash。当前群笔记命中与未命中的两条连续消息会得到不同 hash，因此即使笔记和权限完全没变也会轮换 engine_id，清除 initialized，而且不会重建该群聊天历史。复习露营笔记后接着问「那我该买哪一个」，会丢失刚才比较过的对象。需将正常检索结果与权限/撤回失效分开。验证会话可以在话题变化时续用，撤回共享仍使旧会话及在途投递失效。
