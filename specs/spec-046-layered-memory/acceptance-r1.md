## Spec Coverage
- **R1 换绑隔离通过。** QQ 从入站账号和当前配置生成发言人身份。自动召回和笔记工具共用 `NoteScope`，私聊查询和删除同时限定对端账号与记录写入时的主人/好友身份；同文去重不会跨身份。旧备份沿用原有作者字段，无需原消息仍在库中。普通好友不会看到主人时期的笔记，群内多人仍可回想本群的共同话题。
- **R2 会话连续性通过。** 同一群成员从命中露营笔记及共享事实换到不命中的追问，仍复用原引擎会话；检索结果不决定是否清空上下文。公开会话保存已披露的笔记 ID 并检查共享范围；先前披露的笔记被删或共享被撤销时，在途发送会重新检查，后续会话不沿用已失效的上下文。
- 结合首轮已通过的主人设置与身份、私有画像、候选/确认、视频经历来源与跨入口覆盖，未发现剩余阻断。
