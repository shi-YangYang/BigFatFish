# QQ 群聊三步完善

基线：codex/qq-napcat / e8ab894。需求来自上一轮群聊工具盘点。保持群受众和群记忆，不恢复私聊读取，不做跨群、管理、签到、发文件。不使用真实账号或收费模型，不 commit/push。

1. 普通消息夹带原生表情、转发、卡片、视频、@全体等时仍保留可读正文，不能将未知内容或引用、OCR、卡片、外部人的发言当主人授权，不放宽出站协议。识别自然直接表达，如「发条说说庆祝一下」，区分 QQ 昵称与本群名片。不以简单关键词授权。犹豫、否定、转述不执行；目标不清给有用澄清而非硬做。
2. 授权群的真实主人可明确要求改鱼的 QQ 签名、换头像、发带图说说。根据发言人的身份和设置展示工具，写入时仅允许本条明确要求的动作和字段。图片选启用的内置素材或由主人在该条消息中明确挑选可用于指定用途的图，实际查看后才可用；不把普通群友收藏、旧图、网络图、转发图默认用于空间/头像。不要借此开放资料读取/未请求字段/历史说说。保留设置开关、状态回读、次数限制、不重复写和真实反馈。
3. 群聊接入三个只读能力：本群公告、本群精华和本条被结构化 @ 成员的群名片。不接全量名单，不借查询跨群或任意查人。有限返回公开必要字段，长度、条数和外部内容边界明确。普通群友可以用本群只读能力。没有相关目标时澄清或不提供定向成员查询，不影响未提及时的普通闲聊。

状态：已实现并通过[独立复验](acceptance-r1.md)。隔离 Runtime / DSH 与 OneBot 测试服务验证，未在真实账号上写入。

### 群内实测：口语改签名

主人说「改个简介」时，先问是 QQ 个性签名还是空间简介，不代改群名片。只说「那你改你的签名」时，问签名原文；尤其不能把刚被取消的内容当作新授权。主人在同一条消息明确说 `那你改你的签名，就写「今天也在游！」` 时，只授权修改 QQ 个性签名。没有新增空间资料写权限。

群里的 QQ 工具按身份、群与开关提供，不按句式或关键词过滤。当前聊天模型结合本群上下文判断是执行、追问还是不操作；不再额外调用模型核对意图。程序在下发时检查授权、字段、图片来源及重复写入。主人可以指定签名原文，或让鱼按本群心情写；群聊不因此获得私聊记忆。
