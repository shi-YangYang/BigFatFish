# QQ 消息中的工具执行
主人在 QQ 私聊要求发说说、改自己的昵称，或聊天时希望大肥鱼自然配表情。当前可用的动作应能从用户消息走到实际工具，而不是模型顺嘴拒绝、空口答应或过早结束。普通聊天不强塞图，禁图、否定、缺必要信息和真实不支持不能变成强制写操作。工具展示及提示以当前身份、开关、资源和运行结果为准。保留群聊/私聊数据隔离、访问范围、用量、幂等、回执和图片先看后发。不得自动重试有副作用的写入。

用户已确认：允许已绑定主人在已授权群里明确发令；其他人不变。按本条主人自己写的明确指令，按需提供发说说或改自己昵称的写操作；账号授权与频率限制不变。群里不提供历史说说或私聊记忆，写操作的回执也不得暴露原签名等未请求字段。引用、转述、假设、否定或别人自称主人都不构成授权。

定位依据：原数据库截至 11 月 8 日的留存记录中，两条含「说说」的入站文本都来自主人在群中发言；群模型请求未提供发说说或改昵称的工具。表情工具有实际调用记录，不应归咎为整个链路未安装。未读取用于鉴权的密钥或向平台外发；不以历史样本证明所有报告均源于同一原因。
