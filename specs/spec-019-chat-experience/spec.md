# Spec：简化模型设置与实时聊天反馈

状态：Done，独立验收PASS。

## 背景
用户在测试准备中要求五项修正：模型用途精简（后续确认保留独立语音输入）；聊天默认多模态且承担记忆等任务；错误提示自动消失且位置统一；回复实时流式展示；删除模型高级配置并采用服务端默认。dev基线8e567fe，开始干净。

## 目标
减少配置负担，使用同一聊天模型完成对话、图片理解、记忆与日记整理、活动决策。临时反馈不挤动页面，真实生成内容到达即显示。

## 非目标
不换引擎、框架、UI库或浅海蓝布局，不扩展平台功能，不调用真实账号，不自动打DMG，不推送。不得用前端打字动画伪装流式。

## 当前行为
ModelPurpose含chat/reasoning/vision/memory/asr/tts六种；高级字段为必填且进入DSH请求。Runtime已有增量事件及WebSocket网关，但Chat每700ms拉取消息/工具。全局/审批/诊断错误散落在页面布局内且不自动收起。语音输入依赖独立audio/transcriptions接口，不能由“支持图片”推断支持音频；用户后续明确“语音输入单独拿出来吧”，因此保留独立ASR路由与协议。

## 目标行为
1. 用途只呈现“聊天模型”“语音输入模型”“朗读模型”；图片理解、记忆/日记、推理/活动选择均取聊天路由。聊天多模态默认开启，不再要求勾选视觉能力；模型不支持时明确失败，不能伪称理解成功。
2. 删除高级配置整个区域（显示名称、内部标识、上下文、输出上限、超时、视觉开关）。标识自动生成，展示名默认模型名；保留服务商、地址、模型、密钥、获取列表、测试连接和推理强度。
3. 正常生成不再强制发送旧手填maxTokens等覆盖模型服务默认值；运行时自身必要的取消、请求超时、输入/消息大小与恢复历史预算可用集中内部默认，须与服务端生成参数明确分开。协议强制要求参数时采用上游模型元数据/适配器默认并据实记录，不声称远端可完全省略。诊断固定短请求预算仍是诊断职责。
4. 使用真实实时事件更新正文及工具状态。Desktop经原生宿主认证转发，不把Runtime token泄漏给WebView；Web沿用认证网关。保留初始历史、断线重连补齐、取消、终态和会话切换隔离，避免旧快照覆盖更晚流式消息；不再常态轮询。
5. 临时操作错误统一为固定提示区（桌面右上、窄屏顶部留边），使用现有beUI Alert/Button组合，不挤动主布局；默认5秒关闭、手动关闭、悬停/键盘聚焦暂停。相同错误去重，重复错误不会永远重置计时。保持可访问播报，不自动抢焦点。
6. 消息自身失败/中断状态与真正持续的断线状态保留在对应位置，以免临时通知消失被误认为操作成功。模型诊断成功的耗时结果可紧邻按钮简洁显示；错误通过统一提示区且随编辑/重试失效，不多处重复展示。

## 功能需求
共享配置/路由归一化负责旧数据兼容，所有直接消费者走一致规则；历史模型与会话不删除。旧额外路由不能继续覆盖聊天任务，保存时输出新简化结构。删除高级设置应贯穿API、配置读取、引擎请求，而非仅藏UI后继续提交旧限制。错误提示通过一个共享生命周期实现，审批抽屉与模型诊断使用同一入口；临时发送错误也收敛，历史失败语义保留。

## 边界条件
首次无模型、仅朗读模型、旧六用途配置（chat/asr/tts保留，reasoning/vision/memory归一到chat）、已有会话的模型更新；模型不支持图片、独立语音输入未配置；错误重发/跨页/抽屉/卸载；实时事件在历史响应前后、切换会话、断线重连、取消与迟到片段。

## 技术约束
沿用单根依赖与普通源码模块；不改目录职责、schema或权限策略。范围涉及配置持久化和原生认证传输，按S3仅检查模型/聊天/媒体直接路径，不运行全项目无关测试。真实服务凭据不可输出或提交。

## 兼容性要求
Desktop/Web共用表现；原始历史与密钥保留，归档恢复可读旧配置；既有API调用的老字段以兼容方式归一，不机械破坏脚本。旧DMG为历史产物，本轮开发验证优先。

## 验收标准
- [x] 设置仅聊天/语音输入/朗读三类用途，无高级区；聊天默认多模态，记忆等实际复用聊天模型。
- [x] 旧配置可用，普通OpenAI兼容请求不再带应用强塞的生成上限；必需内部边界与协议默认如实记录。
- [x] Desktop/Web在最终完成前出现多个真实增量，取消/切会话/重连补齐正确，无700ms常态轮询。
- [x] 临时错误位置统一、5秒关闭、可手动关闭与暂停，无布局跳动或抽屉遮挡；失败/断线状态不丢。
- [x] 定向验证与新的独立验收PASS，按持续授权本地commit；不冒称真实账号、Windows或新安装包验证。

无。用户明确“语音输入单独拿出来吧”，最终保留chat/asr/tts三类，语音输入沿用独立转写接口；不新增聊天模型音频协议。
