# 移除顶栏「服务在线」

## 背景
共享顶栏在每一页显示服务状态，同时用状态按钮打开操作菜单。
## 目标
正常使用时把顶栏空间留给页面标题和当前操作。
## 非目标
平台连接页上的账号状态、后台 API 和托盘不属于本次修改。
## 当前行为
顶栏显示在线标签或窄屏圆点，并为暂停菜单定时读取活动列表。
## 目标行为
Desktop/Web 在所有宽度移除该标签和菜单。断线时由现有提示提供重连，活动控制集中到「我的鱼 → 活动计划」，Web 退出放在「设置 → 通用」。
## 功能需求
维持服务可达性检测、断线重连、活动暂停/恢复和 Web 退出能力。移除仅供状态菜单使用的请求、状态及样式。
## 边界条件
首启、初次连接失败、已连接后掉线和窄屏聊天都使用既有布局。活动页可以在空闲时主动暂停。
## 技术约束
沿用共享 App、现有 beUI 控件及现有设置页。
## 兼容性要求
不改数据和对外接口。
## 验收标准
- [x] 正常顶栏无「服务在线」、状态圆点或替代占位，聊天操作和窄屏导航可用。
- [x] 重连、暂停/恢复和 Web 退出有明确入口，状态菜单专用轮询已移除。
- [x] 与本次修改直接相关的界面检查及独立审阅通过。
## 待确认问题
无。
