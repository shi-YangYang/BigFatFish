# Spec 003: P1 AI 鱼核心

状态：Acceptance（代码与本机/Linux路径通过，外部验证待完成）。两项桌面返工及Docker配置已独立审阅PASS；真实SDK/CLI/桌面/Linux镜像验证通过。Windows与真实云模型仍未验证，完整阶段不标Done。

## 背景

已有 Runtime/CLI/SQLite/认证 API 与桌面状态壳；需要真实 DSH 驱动的模型、人格、持久会话和流式聊天。上游实际发布接口及安全边界已记录在 docs/upstreams.md。

## 目标

用户配置模型后可通过 Desktop 与 CLI 和同一条鱼聊天，查看/恢复会话、修改人格、取消任务，重启后保留消息。Agent 引擎经抽象适配，使用官方 DSH，不能以直接模型请求冒充 DSH Adapter。

## 非目标

P2 长期记忆提取、P3–P5 平台账号操作和P7插件市场不在本阶段。上下文持久化不能冒充长期记忆，缺失模型配置不能返回假回复。

## 当前行为

P0提供真实进程、SQLite和状态API；尚无模型配置、聊天或人格存储。

## 目标行为

模型未配置时显示明确引导。用户添加提供商、Base URL、模型名和凭据，设置人格后发送消息，真实输出逐段到达。取消、失败、超时和断线能被区分；历史消息重启后可查，后续消息能恢复同一DSH上下文。

## 功能需求

1. Runtime 统一模型配置和按用途路由，至少真实支持 DeepSeek 与用户指定 OpenAI兼容/本地端点；UI/插件不得各存一套密钥。模型能力与限制显式配置，不宣称任意模型均已验证。
2. API Key 加密保存且不在任何查询响应、日志、错误或profile明文中出现；加密密钥使用系统密钥库或明确受保护的独立本机密钥。备份默认排除密钥。凭据仅传入所选DSH子进程，不能读取其他应用配置。
3. 持久单一人格：名称、头像引用、角色设定、基础性格、说话风格、喜好/厌恶、行为边界、作息与自主活动偏好，并保留人格版本记录。更新在后续回合生效；所有入口读取同一配置。关系、心情与经历由 P2 在此基础上扩展。
4. SQLite版本迁移增加conversations/messages/agent_sessions及必要模型/人格配置，记录消息状态、来源、时间、引擎会话映射。真正恢复引擎会话，不只展示旧消息。
5. AgentEngine普通模块接口封装DSH健康/启动、创建与恢复session、发送、真实流式事件、按任务取消、超时/异常清理。固定实际发布版本0.2.2-alpha.2；同版SDK/引擎，不照抄master缺失API。
6. 受控sdk-minimal overlay禁用内置shell/fs/working-directory及会话日志/包清单上传。通过自有Cordis bridge接收agent/assistant-stream的真实frame、关联root session与attempt/revision；取消调用原生agent.cancel并等待静止。未知工具默认拒绝，不能把profile当OS沙箱。
7. 模型配置通过真实provider插件完成：deepseek-official为Messages接口，OpenAI兼容通过官方llm-pi-ai配置，不能伪造SDK的apiKey/baseURL参数。DSH_HOME使用本产品独立目录，不覆盖HOME或读取其他DSH账户。
8. 认证API管理模型/人格/会话/消息/取消，WebSocket提供有身份关联的消息和任务事件。请求幂等、同会话串行，跨会话不串流；终态必须可靠持久化，重连可重新获取权威状态。
9. Desktop实际可配置模型/人格、选择与创建会话、发送、接收真实流、取消和显示错误；原生桥保护token，UI不直接DB。CLI具备对应可脚本化的模型/人格/聊天/会话命令，不通过argv传递API Key。
10. 运行中断、无模型、错误凭据/端点、模型超时、SDK崩溃、取消与重启后未完成回合有真实可见状态，不能吞错或返回伪成功。

## 边界条件

重复请求、并发同会话、会话恢复失败、persona更新时正在生成、流重试revision、cancel先于引擎就绪、取消后迟到帧、断线与重启、配置删除时正在使用、日志中密钥与URL用户信息、模型返回未知工具调用。日志及状态API不泄露模型内容与凭据。

## 技术约束

普通源码模块、不分公共包；遵循Runtime唯一业务入口。现有P0 schema必须向前迁移。所有生产回复必须经过真实DSH执行，测试HTTP模型仅作为测试夹具并明确标注，不能出现在生产路径。

## 兼容性要求

Node最低版本满足DSH发布要求，CLI/Linux与Desktop复用同一逻辑。已有P0生命周期和认证行为保持。Windows未验证项独立留存，不能阻断macOS/Linux可执行路径，也不能虚报支持。
