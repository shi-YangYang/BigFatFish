# Spec 037：自然用图与 Desktop 易用性

状态：Done；A 独立 PASS，B 返工独立 PASS（acceptance-r1.md），截图覆盖与限制见 Plan。

## 背景
用户反馈大肥鱼常等明确索要才配图，Desktop UI/UX 与流程不适合普通用户，要求联网研究和全量截图检查。用户已选「更活泼：日常闲聊经常配图，尽量少重复」。dev 基线 f321344，工作区干净。本任务没有 commit/push 授权。

## 目标
- QQ 日常回复主动考虑贴切表情，不要求用户先提图片；同一会话尽量换图。
- 逐页操作当前 Desktop，以截图和具体流程确定问题并修复，保留浅海蓝、beUI 和既有功能边界。

## 非目标
不扩张自动消息收件人或平台权限、不随机强塞图、不覆盖自定义人格、不增加收费服务或新的 UI 框架，不重启用户 QQ，不提交代码。

## 当前行为
普通 QQ 消息已获得表情工具，但工具只强调克制，缺少正向配图策略；每轮选图隔离且候选固定排序，没有跨轮近期用图信息。Desktop 具备聊天、我的鱼、连接、设置，但信息与操作密度需以实际截图复核。

## 目标行为
### A：自然用图
问候、撒娇、吐槽、庆祝、得意、晚安等日常情境经常自主寻找贴切图片；认真讨论、用户不要图、没有合适图时用文字。根据最近使用记录优先同样贴切的新图，可明确要求重发，不强制比例或无意义工具调用。

### B：Desktop
检查所有主页面与二级页签、关键菜单/表单/滚动区域，覆盖默认900×680窗口及窄窗口。以实际问题清单约束修改，不凭主观审美推翻现有结构。日常操作突出、次要操作按需展开，状态反馈和用户称呼准确。

## 功能需求
- A1：QQ 的可信内部回合上下文明确鼓励自然主动用图，不拼作用户输入、不更改人格配置、不影响普通本地聊天或后台任务。
- A2：工具描述与策略一致，保留查看成功后才可选择、每轮最多一张、原网络源与限制、最终授权和撤销检查。
- A3：按账号和目标隔离、有界记录近期图；群内不同说话者共享该群近期记录。只在投递 sent 或可能投递 unknown 后计入避重复；失败/取消/拒绝不计。unknown 仍是未知，不算成功。
- A4：本地工具候选和网络截取前排序参考近期使用；不改图库管理顺序，不移除唯一可用图；重启后重新积累可接受，不引入 schema。
- B1：页签内容、选中状态、开关和关键浮层进入时直接可见，不依赖动画帧才显示；焦点提示不裁切，不因切页滞留空白。
- B2：三平台页减少重复标题、巨大连接卡片和返回区占用；维持已连接/登录区别但就近精简呈现，连接/切换/断开职责不变，记录仍在卡片内滚动。
- B3：模型管理默认呈现已有模型/用途，只有新增或编辑才显示编辑表单；保留测试、发现、用途和推理配置，不把已有配置用户带入空白新建态。
- B4：记忆默认呈现记忆列表与添加/整理入口；添加和从对话整理按需打开，选中后才出现批量操作，空列表不堆禁用工具与分页。原持久化行为和冲突检查保持。
- B5：概览不整段展示内部人设；经历日记默认只需日期和生成操作，时区在低频设置内；任务与调度改为用户能理解的活动计划。保留全部既有功能，不新增自动计划。
- B6：QQ只读会话明确与本地聊天区分，发言者不误称你；不能在不可发送的会话仍呈现正常可发送输入。首次进入聊天优先本地会话，不自动落到最新QQ群聊。Runtime依据实际principal提供兼容新增的只读元信息，不按标题猜测、不暴露principal；旧服务缺字段按兼容处理，新行为重启后台生效。
- B7：统一页头/表单/卡片间距和内容宽度，保留40px主要控件、beUI和浅海蓝；窄窗口无横向溢出，少数低频字段按需呈现，不重造多个边栏。

## 边界条件
网络关闭、空库/单图、重复情绪、不同私聊/群/账号、发送失败/未知、删除或禁用图、外部引用内容、现有人格与设置草稿。

## 技术约束
普通模块封装，Runtime 负责回复策略和投递状态；保留 DSH 已呈现图片凭证。现有 beUI 与浅海蓝 token，禁止整库替换和目录迁移。

## 兼容性要求
现有数据库、人格、记忆和授权不迁移；无真实外发和付费模型验证。用户运行的服务保持；新 Runtime 下次正常重启生效。

## 验收标准
- [x] 普通闲聊向 QQ 引擎传达正向配图策略且保持非 QQ 边界。
- [x] 近期用图隔离、更新时机、候选变化与失败/撤权路径正确。
- [x] 所有 Desktop 主要页面和二级入口有截图覆盖/明确限制，具体问题完成修复。
- [x] 修改后的重点流程、布局与必要定向检查通过；新独立 Agent PASS。
- [x] 无擅改用户数据、真实外发、服务重启或 commit。

配图频率已确认。UI 不涉及新产品功能，按实际问题清单收敛。
