# 自动记忆与人物归属

## 目标

聊天中的个人记忆自动生效。大肥鱼能分清发言人的身份、这段记忆属于谁，以及在哪个聊天里可以提起。沿用本机 BGE small INT8。

## 已明确的边界

- 发言人的产品角色取自本机入口或 QQ 核实的发言人、账号和主人绑定。模型消息的 user/assistant 标记不能表示主人身份。
- 桌面与主人 QQ 私聊识别为同一个人。主人在群里仍是主人，场合仍是该群。不得把私聊记忆、其他人的记忆或另一个群的内容带入本群。
- 自动长期记忆保留来源和原话，可查看、更正和删除。既有候选、拒绝和人工编辑记录不批量升级。鱼的观看经历保持独立。
- 只在隔离库和模拟会话验证。无真实账号操作、用户现用数据库迁移或 Git 提交。

## 写入和回忆

- 私聊好友按已授权的 QQ 好友身份保留独立记忆。群里的发言标明实际说话人，只在原群回忆。主人本人在群里说过的可记事实，同时可以回到桌面或主人私聊回忆。一次发言保存一份有来源的记录。
- 自动写入由可复现的本地条件触发。明确请记住、称呼、稳定自述、已经确定的安排是典型例子。日常寒暄、推测、转述、密码和明确拒记跳过。一次消费或临时心情不自动概括为长期偏好。发言人由运行时提供，文本里的自称不改变角色。保留原话和发生时间。既有手动整理/历史候选可继续管理。
- 同一人的明确更正优先于旧的自动结论。遇到无法可靠判定的冲突，保护已有的人工修改和已拒绝内容。用户可编辑或删除自动记录。

## 验收场景

1. 主人和两个不同好友说同样的喜好，后续各自在原范围回忆。群里的人无法用同一句话改写主人画像。
2. 主人在 A 群明确说过的安排出现在 A 群及主人私聊，B 群或其他好友私聊读不到。A 群普通群友的陈述可用于 A 群，作者仍然可区分。
3. 普通聊天完成后即可使用合格的记忆，无逐条确认或后台云模型决定写入。既有关键词和本机 small 语义检索、内置工具、公开回复投递守卫遵守同一范围。
4. 迁移和备份保留来源与人物归属，未知历史来源不越权。自动记忆可纠正和删除，不能跨人去重或合并。
