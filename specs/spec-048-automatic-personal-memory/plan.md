# 实施与验证

本次涉及持久化和权限，属 S3。实施分别覆盖来源身份核验、记忆存储与受众隔离、写入规则与聊天入口。按现有管理和备份接口兼容旧数据。验证重点是同一句话由不同的人说出时能否正确归属、正常对话中自动产生的记忆能否在允许的场合延续、拒绝和删除是否生效，以及已有数据能否升级和恢复。

## 实施记录

数据使用 schema 9。自动写入保留来源消息、人物角色与原场合。读权限、向量召回和关键词查询遵循相同的范围；主人私聊对跨场合的称呼、名字和同一事物的喜好采用最新有来源的声明。群内保留其自身的公开说法。公开会话只追踪实际披露的记忆及版本，正常新增记录不阻断回复。

通过定向的身份核验、写入规则与更正、存储/迁移/备份、会话与笔记工具和真实 small 语义检索验证。新增的正常对话联测逐项核对主人私聊、两个好友与两个群的提示和工具输出，包括群内带 @ 的消息，以及自动写入无额外模型调用。QQ 的协议夹具检出一个共享单字主题的中文召回漏项，按完整主题补足后重新通过。生产 Node 构建与双端及相关集成测试文件的 TypeScript 检查通过。未使用真实账号、云端聊天额度或用户的现用数据。

Chromium 验证了按角色筛选、来源群展示和共享按钮范围。首轮独立验收发现未决想法误入库、QQ 正常静默漏记，返工后的正反例和模拟 OneBot 投递通过，生产 Node 构建通过。[独立复验](acceptance-r1.md)
