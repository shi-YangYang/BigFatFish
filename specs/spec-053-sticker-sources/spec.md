# QQ 表情来源分区

状态：Done。风险 S0，仅局部展示与文案。

## 背景与目标
用户截图中网络开关与本地图片网格混在同一卡片，容易误认为图片来自网络或受网络开关控制。要求区分网络图片和本地表情，将「添加图片」改成「添加表情」，并解释实际网络触发时机。

## 当前与目标行为
「网络表情」独立区域展示既有网络开关及梗鲸来源链接；「本地表情」独立区域展示现有网格与添加操作。标题、间距和控件沿用既有组件，保持简单清楚。上传入口改为「添加表情」。

## 范围与约束
只改 QQStickers 展示层及必要局部样式、现有 QQ 文档。既有 API、状态、上传/删除/启停、图库范围与模型选择策略保持。没有网络图片常驻网格，不假装网络候选已存本地；本地包括内置、上传与聊天收藏图片。无需新依赖、迁移或新接口。不操作真实账号。用户随后明确授权本地 commit，不包含 push。

## 验收
- [x] 网络与本地有独立可见标题及容器，添加表情入口属于本地。
- [x] 「添加图片」改为「添加表情」，添加和取消流程保持。
- [x] 本地滚动网格、预览、启停与删除，以及网络开关请求保持。
- [x] 简洁且窄宽可换行；无业务策略改动。
- [x] S0 diff 检查和独立验收通过，不运行测试/build/lint/typecheck。

## 非目标与待确认
不新增图库管理、来源持久化或收藏策略。无待确认问题。
