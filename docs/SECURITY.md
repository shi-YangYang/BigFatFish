# 安全说明

## 当前状态

项目处于仓库初始化阶段，尚未发布可运行版本，也没有已声明的受支持版本。产品中的权限隔离、审批、凭据存储和审计仍是待实现目标，不代表现有安全保证。

## 报告问题

请勿在公开 Issue、PR 或日志中披露真实密钥、Cookie、用户数据或可直接利用的漏洞细节。本仓库尚未公布专用安全联系地址；可先以不含敏感细节的方式向维护者询问私密报告渠道，再提供复现步骤、影响范围和经过脱敏的证据。

不假定仓库已开启私密漏洞报告功能，也不承诺尚未建立的响应时限。

## 开发约束

- 运行数据与安装目录、源码分离；本地开发数据约定存于被忽略的 `.local/bigfatfish/`。
- `.env`、凭据与浏览器会话不得提交；示例配置只放占位值。Git 忽略规则不能代替内容检查。
- 平台写操作、远程管理、插件权限及密钥管理按 [产品安全目标](product-design.md#12-权限与安全) 实施和验收。
- 引入外部项目时先审查来源、版本、许可证、依赖和权限，不将同进程插件加载称为安全沙箱。
